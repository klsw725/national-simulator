# 작업 요약: 분석 탭에서 디브리프 모달이 뜨는 버그 수정

## 사용자 프롬프트

```text
지금 시뮬레이션 완료후 분석 탭을 누르면 디브리프 창이 떠서 분석 탭을 확인을 못하는 버그가 있어 수정해줘
```

## 원인

- `SimulationPanel.tsx` line 77의 WarRoom 렌더 조건이 `wargameCompleted && tab !== "report"`로만 제한되어 있었다.
- 시뮬레이션 완료 후 분석 탭(graph, geopolitics, timeline, causal, export, conversation)을 클릭해도 여전히 WarRoom이 렌더됐고, WarRoom 안에서 `useWargame`의 `setIsComplete(true)` → `setShowDebrief(true)` 체인이 자동으로 디브리프 오버레이를 띄웠다.
- 결과적으로 분석 탭 콘텐츠에 접근할 수 없었다.

## 변경 사항

- `frontend/src/components/simulation/SimulationPanel.tsx`
  - WarRoom 렌더 조건에 `!analysisOrSystemTab` 가드 추가
  - 분석 그룹(graph, geopolitics, timeline, causal, export, conversation) 또는 시스템 그룹(dashboard, health) 탭 선택 시 WarRoom 대신 SimulationPanel 본문이 렌더됨
