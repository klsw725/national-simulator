# 작업 요약: 시뮬레이션 시드 메타 응답 검증 추가

## 사용자 프롬프트

```text
시뮬레이션 다시 돌려보고 에러가 발생하면 원인 찾아

시뮬레이션 실행할때는 고급으로 해서 웹검색 보강, 지정학 이벤트 발생시켜서 진행하고
```

## 재현 내용

- 고급 설정 기준으로 시나리오를 재실행했다.
- `web_search_enabled=true`, `wargame_enabled=true`, `geopolitics_mode=game_master`로 실행했다.
- 초기 재현에서는 시드 문서가 실제 시나리오 문서가 아니라 메타 지시문(`We need to produce markdown...`)으로 생성됐다.
- 그 결과 MiroFish 온톨로지/그래프 단계 뒤에 그래프가 `0 nodes / 0 edges`로 만들어졌고, prepare 단계에서 `조건에 맞는 엔티티를 찾을 수 없습니다` 오류가 발생했다.

## 원인

- Gateway `SeedGenerator`가 LLM 응답을 그대로 저장하고 있었다.
- 일부 응답에서 최종 시드 문서 대신 프롬프트/작업계획 형태의 메타 텍스트가 반환될 수 있었고, 이 경우 후속 그래프 추출이 실패했다.

## 변경 사항

- `backend/app/services/seed_generator.py`
  - 메타/지시문 형태의 잘못된 시드 응답을 감지하는 검증 로직 추가
  - 잘못된 응답이면 더 강한 제약 문구로 1회 재시도
  - 재시도 후에도 유효하지 않으면 명시적으로 실패 처리

## 검증

- `python -m py_compile backend/app/services/seed_generator.py`
- 수정 후 재실행한 시나리오 `scn_f91bc8f8c61f`에서:
  - 시드가 실제 한국어 지정학 문서로 생성됨
  - 이전 실패 지점이던 empty graph 재현되지 않음
  - MiroFish 상태 확인 결과 `entities_count=13`, `status=preparing`

## 비고

- 웹 검색은 DuckDuckGo rate limit(403)로 일부 실패했지만 시드 생성 자체는 계속 진행됐다.
- 수정 후 파이프라인은 기존 실패 지점(빈 그래프 → prepare 실패)을 통과했다.
