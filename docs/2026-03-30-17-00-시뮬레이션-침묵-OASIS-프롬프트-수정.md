# 시뮬레이션 침묵 근본 원인 — OASIS 에이전트 프롬프트에 행동 규칙 미주입

## 프롬프트

시뮬레이션에서 라운드 0에만 포스팅이 되고 그 이후 라운드에서 조용한 현상. `scn_94bab8678e33`, `scn_5c57740b8b38` 시나리오에서 동일하게 발생. `geopolitics_enabled` 여부 무관.

## 진단 과정

### 1차 가설: activity_level 부족 → 기각
- `sim_6627fbffbeb7` config 확인: activity_level 평균 0.71, US=0.85, 24시간 활성
- 시뮬레이션 로그: "9 agents active" 매 라운드 출력
- **에이전트는 매 라운드 정상 선택됨**

### 2차 가설: MiroFish 시뮬레이션 미실행 → 부분 확인
- `twitter_status: not_started` (MiroFish API) → 실제로는 실행됨 (상태 업데이트 누락)
- `simulation.log` 확인: 30라운드 정상 완료, 193초 소요

### 3차 가설 (확정): LLM이 refresh만 선택
- OASIS SQLite `trace` 테이블: `refresh: 143`, `create_post: 12` (initial_posts만), `sign_up: 16`
- **30개 라운드에서 에이전트가 총 143회 refresh(타임라인 보기)만 실행**
- `_fetch_new_actions()`는 `refresh`와 `sign_up`을 필터링 → actions.jsonl에 0건

### 근본 원인
OASIS의 시스템 프롬프트:
```
You're a Twitter user. After you see the posts, choose some actions.
Your actions should be consistent with your self-description.
```

`user_char`에는 페르소나 설명만 있고 "적극적으로 포스팅하라"는 지시 없음.
`GEOPOLITICS_PERSONA_PROMPT`는 `geopolitics.py`에 정의되어 있지만, `build_geopolitics_profile()` 함수에서만 사용되고 **이 함수는 어디서도 호출되지 않음** (dead code).

실제 경로:
```
oasis_profile_generator._save_twitter_csv() → user_char = bio + persona → CSV
→ OASIS generate_twitter_agent_graph() → UserInfo.to_system_message()
→ GEOPOLITICS_PERSONA_PROMPT 누락
```

## 수정

### 변경 파일 1: `external/mirofish-backend/app/services/oasis_profile_generator.py`
`_save_twitter_csv()` 메서드에서 지정학 엔티티가 포함된 시나리오인 경우, `user_char`에 `GEOPOLITICS_PERSONA_PROMPT`를 append:

- 프로필 목록에서 `source_entity_type`이 지정학 타입(superpower, regionalpower 등)인 것이 하나라도 있으면 지정학 시나리오로 판정
- 모든 에이전트의 `user_char` 끝에 행동 규칙 추가

### 변경 파일 2: `external/mirofish-backend/app/services/simulation_config_generator.py` (이전 작업)
LLM이 반환한 activity_level에 규칙 기반 최소값 강제 (지정학 시나리오).

### 효과
1. OASIS 에이전트의 시스템 프롬프트에 "첫 행동 DO_NOTHING 금지, CREATE_POST/QUOTE_POST 우선" 규칙이 주입됨
2. LLM이 refresh 대신 적극적 행동을 선택하도록 유도
3. activity_level 최소값 보장으로 에이전트 선택률도 보장

## 참고: Docker 환경 주의
MiroFish는 Docker 컨테이너(`osint-simulator_mirofish_1`)에서 실행됨. 파일 수정 후 컨테이너를 재빌드해야 적용됨:
```bash
docker-compose build mirofish && docker-compose up -d mirofish
```
