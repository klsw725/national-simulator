# 레거시 지정학 개입모드 1단계 제거

## 프롬프트

> 기존 지정학 개입모드는 불 필요할것 같은데 그럼 → 얍

## 목적

v11 워게임 루프가 기존 post-simulation 지정학 개입모드를 사실상 대체하므로,
레거시 전용 진입점과 UI를 제거하고 워게임 중심 경로만 남긴다.

## 변경 사항

### 프론트엔드

- `frontend/src/components/simulation/SimulationPanel.tsx`
  - `interactive` 탭 제거
  - `simulating:geopolitics_paused` 전용 렌더링 경로 제거
  - 레거시 pause 버튼 제거
- 삭제:
  - `frontend/src/components/simulation/InteractiveSimulationView.tsx`
  - `frontend/src/components/simulation/GeopoliticsDecisionView.tsx`
  - `frontend/src/lib/api/interactiveApi.ts`
- `frontend/src/lib/gatewayApi.ts`
  - `interactiveApi` export 제거
- `frontend/src/types/simulation.ts`
  - `PipelineMode`에서 `interactive` 제거 (`auto | checkpoint`만 유지)

### 백엔드

- `backend/app/routers/simulation_run.py`
  - `/simulate`에서 `mode=interactive` 차단
  - `CHECKPOINT_STEPS`에서 `simulating:geopolitics_paused` 제거
  - `continue_pipeline()`에서 레거시 `simulating:geopolitics_paused` 분기 제거
  - 레거시 decision option 생성 helper 제거
- `backend/app/main.py`
  - `simulation_interactive` router 등록 제거
- 삭제:
  - `backend/app/routers/simulation_interactive.py`
- `backend/app/services/simulation_orchestrator.py`
  - post-simulation interactive geopolitics 호출 제거
  - 비워게임 경로에서도 지정학은 분석 전용(`_step_geopolitics_analysis`)으로만 수행
  - `_step_geopolitics_interactive()` dead code 제거

## 검증

- `python3 -m py_compile backend/app/main.py backend/app/routers/simulation_run.py backend/app/services/simulation_orchestrator.py` 통과
- `docker compose build gateway frontend` 통과
- 코드베이스 검색으로 다음 레거시 참조 제거 확인:
  - `InteractiveSimulationView`
  - `GeopoliticsDecisionView`
  - `interactiveApi`
  - `simulation_interactive`
  - `simulating:geopolitics_paused`

## 남겨둔 것

다음은 워게임과 공유되므로 삭제하지 않음:

- `decision_points`
- `geopolitics_snapshots`
- `geopolitics_events`
- `geopolitics_interactive.py`의 shared helper (`should_pause`, option builders, snapshot helpers)

## 후속

- `What-If` 탭은 워게임과 성격이 달라 유지
- `결정` 탭은 seed/parameter checkpoint에 여전히 필요하여 유지
