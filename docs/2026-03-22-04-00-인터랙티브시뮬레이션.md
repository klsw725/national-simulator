## 변경 요약

### M1: 라운드별 일시정지 API
- `backend/app/models/interactive.py` 신규: InteractiveSimulationConfig, InjectEventRequest, InteractiveStatus 모델
- `backend/app/routers/simulation.py` 수정:
  - GET `/interactive_status`: 현재 라운드, 일시정지 상태, 텐션 알림 수, 주입된 이벤트 수
  - POST `/simulation/pause`: MiroFish stop_simulation() 호출 → paused:round_N 상태 설정
  - POST `/simulation/resume`: run_from_failure()로 남은 라운드 백그라운드 실행

### M2: 이벤트 주입 API
- `backend/app/database.py` 수정: injected_events 테이블 추가 (id, scenario_id, result_id, event_type, content, target_agents, injected_at_round, status)
- `backend/app/routers/simulation.py` 수정: POST `/simulation/inject_event` — 일시정지 중 이벤트 저장 (pending)

### M4: 프론트엔드 InteractiveSimulationView
- `frontend/src/components/simulation/InteractiveSimulationView.tsx` 신규:
  - 5초 폴링으로 interactive_status 실시간 업데이트
  - 진행률 바 (그라디언트: 실행=cyan, 일시정지=amber, 완료=green)
  - 라운드 타임라인 (● 완료, ◉ 현재/일시정지 펄스, ○ 대기)
  - Pause/Resume 제어 버튼
  - 이벤트 주입 폼 (일시정지 시만 표시)
  - 텐션 알림 배너
- `frontend/src/lib/gatewayApi.ts` 수정: getInteractiveStatus, pauseSimulation, resumeSimulation, injectEvent
- `frontend/src/components/simulation/SimulationPanel.tsx` 수정: "인터랙티브" 탭 추가

### M5: AI 개입 제안 엔진
- `backend/app/services/tension_analyzer.py` 신규: TensionAnalyzer
  - 라운드별 액션 분석 (군사/위협/공격/제재 키워드 기반)
  - tension_threshold 초과 시 DecisionPoint 생성 (계속/일시정지/긴장완화 3개 옵션)

### 미구현 (MiroFish IPC 종속)
- M3 (What-If 분기): MiroFish 시뮬레이션 상태 스냅샷 + 별도 인스턴스 실행이 필요하여 MiroFish 측 지원 대기
