## 변경 사항

### 수정 파일

- `backend/app/routers/simulation.py`
  - `mode=interactive` 지원: start_simulation에서 3번째 모드 추가
  - `_generate_decision_options()` 백그라운드 함수: SeedGenerator.generate_options() + recommend_params() 호출 → DecisionPoint 2개 생성 → status를 checkpoint:decision으로 설정
  - `CHECKPOINT_STEPS`에 checkpoint:decision 추가
  - `get_checkpoint`에서 checkpoint:decision 처리: pending decision point ID/type 목록 반환
  - `continue_pipeline`에서 checkpoint:decision 처리: resolved DP에서 선택된 시드 텍스트 + 파라미터를 DB에 적용 → checkpoint:seed로 전환 → 기존 checkpoint 파이프라인 재개
  - `import get_pool` 추가

- `frontend/src/types/simulation.ts`
  - PipelineMode에 'interactive' 추가

- `frontend/src/components/simulation/PipelineProgress.tsx`
  - generating_options, checkpoint:decision → step 0으로 매핑

- `frontend/src/components/simulation/SimulationPanel.tsx`
  - checkpoint:decision일 때 CheckpointReview 대신 DecisionPointView 2개 (seed + params) + "선택 완료" 버튼 표시

### 설계 결정

- interactive 모드는 기존 auto/checkpoint 모드와 호환: 옵션 생성 후 checkpoint:seed로 전환하여 기존 checkpoint 파이프라인을 재활용
- continue_pipeline에서 모든 pending DP가 resolved인지 검증 (미해결 시 400 에러)
- 선택된 시드 텍스트는 seeds 테이블의 최신 행을 업데이트
- 선택된 파라미터는 scenarios.max_rounds + scenarios.simulation_params를 업데이트
