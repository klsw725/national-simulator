# V9 인터랙티브 지정학 — 듀얼 모드 구현

> 날짜: 2026-03-30
> PRD: docs/prds/v9-interactive-geopolitics.md

## 프롬프트

시뮬레이션에서 지정학 이벤트가 발생하면 정지 후 이 이벤트에서 어떻게 행동하면 좋을지 선택지를 제공하고 그 선택한 선택지에 따라 시뮬레이션이 진행되는 기능. 두 가지 모드: (1) 특정 국가 역할 수행 (actor_role), (2) 시나리오 방향 결정 (game_master).

## 변경 사항

### M1: DecisionEngine 라운드 분리

**수정**: `backend/app/geopolitics/engine.py`

- `_action_overrides` dict 추가 (1회성 행동 오버라이드)
- `override_next_action()` — actor_role 모드에서 특정 국가 행동 오버라이드
- `apply_direction_deltas()` — game_master 모드에서 전체/적대/동맹 actor state 일괄 조정
- `run_single_round()` — 라운드 1개 실행 후 오버라이드 초기화
- `serialize_state()` / `from_state()` — 엔진 상태 스냅샷 직렬화/복원
- `decide_actions()` — 오버라이드 존재 시 규칙 대신 오버라이드 사용
- `run_simulation()` — 내부적으로 `run_single_round()` 사용하도록 리팩토링 (하위호환)

### M2: 모델 + 스키마 확장

**수정**: `backend/app/models/scenario.py`
- `GeopoliticsMode` enum 추가 (AUTO, ACTOR_ROLE, GAME_MASTER)
- `SimulationParams`에 4개 필드 추가: geopolitics_mode, geopolitics_player_actor_id, geopolitics_rounds, geopolitics_pause_threshold

**수정**: `backend/app/models/decision_point.py`
- `DecisionPointType`에 2개 추가: GEOPOLITICS_ACTOR_RESPONSE, GEOPOLITICS_DIRECTION

**수정**: `backend/app/database.py`
- `geopolitics_snapshots` 테이블 추가 (엔진 상태 스냅샷 보존용)

### M3: 핵심 로직 + 통합

**신규**: `backend/app/services/geopolitics_interactive.py`
- `should_pause()` — 모드별 일시정지 판정 (magnitude 임계치 + cascade 발생)
- `build_actor_response_options()` — actor_role용 행동 선택지 7종 생성
- `build_direction_options()` — game_master용 방향 선택지 4종 생성
- `find_trigger_event()` — 플레이어 관련 최고 magnitude 이벤트 탐색
- `save_geopolitics_snapshot()` — 엔진 상태 DB 저장
- `create_geopolitics_decision_point()` — DecisionPoint 생성
- `link_snapshot_to_dp()` — 스냅샷-DecisionPoint 연결

**수정**: `backend/app/services/simulation_orchestrator.py`
- `_init_geopolitics_engine()` — 엔진 초기화 로직 공통 헬퍼로 추출
- `_step_geopolitics_interactive()` — 라운드별 실행 + should_pause + DecisionPoint 생성 + paused 상태 반환
- 호출부 분기: mode != AUTO → interactive path, paused 시 return (completed 방지)

**수정**: `backend/app/routers/simulation.py`
- CHECKPOINT_STEPS에 `simulating:geopolitics_paused` 추가
- `continue_pipeline()`에 지정학 재개 로직: 스냅샷 복원 → 선택 반영 → 나머지 라운드 실행 (재일시정지 가능)

### M4: 프론트엔드 — GeopoliticsDecisionView

**신규**: `frontend/src/components/simulation/GeopoliticsDecisionView.tsx`
- Actor Role UI: 트리거 이벤트 + 내 국가 상태 바 + 행동 선택 카드 7종
- Game Master UI: 라운드 요약 + 방향 선택 카드 4종 (2×2 그리드)
- 선택 → resolve → continueSimulation → onResolved

**수정**: `frontend/src/components/simulation/SimulationPanel.tsx`
- `simulating:geopolitics_paused` 상태에서 GeopoliticsDecisionView 렌더링

### M5: 시뮬레이션 설정 UI

**수정**: `frontend/src/components/simulation/ScenarioForm.tsx`
- geopolitics_mode 드롭다운 (자동/국가역할/게임마스터)
- actor_role 선택 시 player_actor_id 텍스트 입력

**수정**: `frontend/src/types/simulation.ts`
- `GeopoliticsMode` 타입 추가
- `DecisionPointType`에 2개 타입 추가

## 아키텍처 흐름

```
시뮬레이션 완료 → geopolitics_mode 확인
├─ auto → 기존 _step_geopolitics_analysis (3라운드 일괄)
└─ actor_role/game_master → _step_geopolitics_interactive
    └─ 라운드 1 → should_pause? → DecisionPoint 생성
        └─ status: simulating:geopolitics_paused
            └─ 사용자 선택 → continue → 선택 반영 → 라운드 2 → ...
```
