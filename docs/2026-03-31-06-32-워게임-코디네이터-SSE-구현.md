# 작업 기록: M4 워게임 코디네이터 + M5 SSE 구현

## 사용자 프롬프트(원문)

1. TASK: Implement M4 (Orchestrator Wargame Coordinator) + M5 (SSE real-time event stream). M4 is the core wargame loop in the orchestrator. M5 provides real-time frontend updates via SSE.

2. EXPECTED OUTCOME:
- `SimulationParams` extended with `wargame_enabled` and `wargame_idle_ttl_minutes`
- New `wargame_state` DB table for round-by-round state persistence
- `run_wargame_pipeline()` method on SimulationOrchestrator
- `_continue_wargame()` resume logic
- Heartbeat + TTL management for paused processes
- SSE endpoint `GET /api/scenario/{id}/events` with 6 event types
- Event bus for pub/sub between orchestrator and SSE
- `simulation_run.py` routes `wargame_enabled=True` to wargame pipeline

3. REQUIRED TOOLS: Read, Write, Edit, Grep, Glob, Bash, LSP tools

4. MUST DO:
- Step 0~8 지시사항(코드 정독, 모델/DB 확장, event bus + SSE 라우터 추가, run_wargame_pipeline/_continue_wargame 구현, 라우팅, 검증)

5. MUST NOT DO:
- 새 의존성 추가 금지, external/frontend/geopolitics engine 핵심 파일 미수정, commit 금지, 기존 run_pipeline 유지

## 구현 내용

- `backend/app/models/scenario.py`
  - `SimulationParams`에 아래 필드 추가:
    - `wargame_enabled: bool = False`
    - `wargame_idle_ttl_minutes: int = 30 (1~120)`

- `backend/app/database.py`
  - `wargame_state` 테이블 및 `idx_wargame_state_scenario` 인덱스 추가

- `backend/app/services/event_bus.py` (신규)
  - asyncio Queue 기반 채널 pub/sub event bus 싱글턴(`event_bus`) 추가

- `backend/app/routers/simulation_events.py` (신규)
  - `GET /api/scenario/{scenario_id}/events` SSE 스트림 추가
  - `StreamingResponse`로 `event: ...\ndata: ...\n\n` 포맷 전송

- `backend/app/main.py`
  - `simulation_events` 라우터 등록

- `backend/app/services/simulation_orchestrator.py`
  - 워게임 제어용 핵심 메서드 추가:
    - `run_wargame_pipeline(...)`
    - `_continue_wargame(...)`
    - `continue_wargame(...)`
  - 서브프로세스 제어/IPC 메서드 추가:
    - `_start_wargame_process`, `_send_control_signal`, `_read_control_signal`
  - 라운드 루프/저장/이벤트 보조 메서드 추가:
    - `_run_wargame_round_loop`, `_save_wargame_state`, `_save_round_actions`, `_save_geopolitics_events_for_round`
    - `_start_heartbeat_loop`, `_cancel_heartbeat_task`, `_is_latest_decision_resolved`, `_finalize_wargame`
  - SSE 이벤트 emit 추가:
    - `phase_change`, `round_complete`, `decision_required`, `decision_resolved`, `round_stats`, `simulation_complete`

- `backend/app/routers/simulation_run.py`
  - 시작 시 `simulation_params.wargame_enabled=True`면 `run_wargame_pipeline` 실행
  - `continue` 엔드포인트에서 `wargame:paused:round_N` 상태 재개 분기 추가
