# MiroFish 지정학 시나리오 에이전트 행동 패턴 수정

**날짜**: 2026-03-28
**프롬프트**: "MiroFish 에이전트 생성 프롬프트가 중국 소셜미디어 패턴으로 하드코딩되어 있어 지정학 시나리오에서 모든 국가 행위자가 침묵함. 수정해보고 판단하자."

## 문제

`simulation_config_generator.py`의 에이전트 프로필 생성 프롬프트가 중국 국내 소셜미디어 여론 시뮬레이션용으로 설계됨:
- 국가 행위자(Superpower/RegionalPower): activity_level 0.2-0.4 (매우 소극적)
- system prompt: "중국인 생활 패턴에 부합해야 합니다"
- 해상 안보 지정학 시나리오에서 모든 행위자가 DO_NOTHING 선택

## 변경 사항

**파일**: `external/mirofish-backend/app/services/simulation_config_generator.py`

### 1. `_is_geopolitical_scenario()` 클래스 메서드 추가
엔티티 타입 목록에서 지정학 엔티티(Superpower, RegionalPower, MilitaryAlliance 등) 존재 여부로 시나리오 유형 자동 판별.

### 2. `_generate_agent_configs_batch()` 프롬프트 분기
- 지정학 시나리오: 국가 행위자 activity_level 0.7-0.9, 24시간 활동, 공식 입장 표명 필수
- 기존 시나리오(소셜미디어): 변경 없음 (중국 생활 패턴 유지)

### 3. `_generate_agent_config_by_rule()` 규칙 기반 폴백 수정
지정학 엔티티일 때 더 높은 활동 파라미터 적용:

| 엔티티 타입 | 기존 activity | 수정 후 activity | 기존 posts/hr | 수정 후 posts/hr |
|---|---|---|---|---|
| Superpower/RegionalPower | 0.3 | 0.75 | 0.2 | 1.0 |
| InternationalOrganization | 0.2 | 0.6 | 0.1 | 0.5 |
| MilitaryCommander | 0.2 | 0.6 | 0.1 | 0.5 |
| Diplomat | 0.35 | 0.7 | 0.15 | 0.6 |

비지정학 엔티티(University, Student 등)는 기존 값 유지.

## 기존 코드 영향

- 기존 소셜미디어 시나리오(중국 패턴): `_is_geopolitical_scenario()` = False → 기존 프롬프트 + 기존 규칙 사용. **변경 없음.**
- 지정학 시나리오: 새 프롬프트 + 새 규칙 적용. 국가 행위자가 적극적으로 행동.
