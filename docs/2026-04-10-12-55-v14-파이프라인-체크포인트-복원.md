## 변경 요약

LangGraph setup 단계에 수동 checkpoint 노드를 추가해 단계별 검토 모드를 복원하고, 프론트엔드에서 `checkpoint_reached` SSE를 받아 `CheckpointReview`를 렌더링하도록 연결했다.

### 백엔드

| 파일 | 변경 |
|------|------|
| `simulation-service/app/graph/nodes/checkpoints.py` | seed/graph/profiles/config 단계 checkpoint interrupt 노드 추가 |
| `simulation-service/app/graph/builder.py` | analyze → review_relations → build_relations → review_profiles → create_actors → review_config → configure_sim → review_geopolitics → simulation_loop 구조로 재배선 |
| `simulation-service/app/graph/state.py` | `pipeline_mode`, `completed_checkpoints` 필드 추가 |
| `simulation-service/app/services/command_listener.py` | mode별 graph 선택, `pipeline_checkpoint` interrupt를 `checkpoint_reached` SSE로 변환, resume 시 `Command(resume=...)` 사용 |
| `simulation-service/app/services/event_emitter.py` | `emit_checkpoint_reached()` 추가 |
| `backend/app/routers/simulation_v2.py` | `/simulate`, `/start_v2` payload에 `mode` 전달 |

### 프론트엔드

| 파일 | 변경 |
|------|------|
| `frontend/src/hooks/useSimulation.ts` | `checkpoint_reached` SSE 핸들러 추가, `checkpointData`/`pipelineStatus` 갱신 |
| `frontend/src/components/simulation/CheckpointReview.tsx` | graph/profiles/config 단계 데이터 표시 보강 |
| `frontend/src/components/simulation/ScenarioForm.tsx` | 기존 mode 토글 재사용 (auto / checkpoint) |
| `frontend/src/components/simulation/SimulationTimeline.tsx` | `action_type` undefined guard 추가 |

## 검증

fresh scenario `scn_33cf09aaef08` 기준:

1. `POST /api/scenario/{id}/simulate {"mode":"checkpoint"}`
   - `checkpoint_reached(step=seed)` 확인
   - `status.simulation_status = paused` 확인
2. `POST /api/scenario/{id}/continue`
   - `checkpoint_reached(step=graph)` 확인
3. 다시 continue
   - `checkpoint_reached(step=profiles)` 확인
4. 다시 continue
   - `checkpoint_reached(step=config)` 확인

즉, setup 단계별 pause/resume가 end-to-end로 동작함을 확인했다.
