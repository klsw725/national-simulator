
## 아키텍처 변경

```
Before (플랫 그래프):
  START → analyze → relations → actors → configure
        → run_round → results → check_intervention → [loop] → report → END

After (부모 + 서브그래프):
  부모: START → analyze → relations → actors → configure → [simulation_loop] → report → END
  서브: START → run_round → results → evaluate_events → [loop/HIT] → END
```

## HIT 트리거 우선순위

1. 캐스케이드 반응 (연쇄 이벤트 >= 1건)
2. 고강도 군사 행동 (magnitude >= 0.7)
3. 긴장도 임계값 (max tension >= 0.6)
4. 방향 체크포인트 (N라운드마다)

쿨다운: 이벤트 트리거(1, 2)는 마지막 HIT 이후 2라운드 미경과 시 스킵. 긴장도/방향은 쿨다운 무관.
