## 변경 요약

### 트랙 A: 전체 OSINT 피드 통합

**M1: 타입 + 폴링 확장**
- `frontend/src/types/dashboard.ts`: 12개 신규 인터페이스 추가 (UAV, CCTV, KiwiSDR, Earthquake, PowerPlant, Datacenter, GPSJamming, InternetOutage, FIRMSFire, SpaceWeather). LiveDataFast/Slow/PollingState 확장.
- `frontend/src/hooks/useDataPolling.ts`: pollFast에서 8개 필드 추출 (ships, military_flights, satellites, uavs, tracked_flights, cctv, gps_jamming, liveuamap). pollSlow에서 12개 필드 추출. freshness 머지 로직 추가.

**M2: 시드 생성 확장**
- `backend/app/services/seed_generator.py`: 9개 신규 _summarize_* 메서드 추가. SEED_GENERATION_PROMPT에 3개 섹션 추가 (군사 기지 배치, 특별 추적 항공기, 무인기 활동). _collect_and_summarize에서 전체 호출 연결.
- KiwiSDR은 lng_key="lon" 적용 (AGENTS.md 지뢰 준수).

**M3: GeoJSON 빌더 + 지도 레이어**
- `frontend/src/components/map/geoJSONBuilders.ts`: 10개 빌더 함수 추가. CCTV/KiwiSDR은 `lon` 필드 사용.
- `frontend/src/components/map/MaplibreViewer.tsx`: 10개 Source/Layer 등록, 8개 팝업 인터페이스 + 클릭 핸들러. (885줄 → 1903줄)

**M4: 레이어 토글 리팩토링**
- `frontend/src/components/map/LayerToggle.tsx`: 플랫 4개 토글 → 5개 카테고리 그룹 (군사/인프라/SIGINT/환경/정보). 카테고리 전체 on/off + 개별 토글 + 카운트 표시.

### 트랙 B: OSINT 상황 패널

**M5: 패널 기본 구조**
- `frontend/src/components/osint/OSINTPanel.tsx`: 좌측 400px 고정 사이드바, 4탭 (요약/자산/피드/선도), 접이식.

**M6: 상황 요약 + 자산 탭**
- `frontend/src/components/osint/OverviewTab.tsx`: 긴장도 게이지 (GDELT tension_score 기반), 자산 현황 (유형별 카운트), 최근 이벤트 (시간순), 경제 지표 (방산주/에너지).
- `frontend/src/components/osint/AssetsTab.tsx`: 국가별 접이식 그룹, 자산 유형별 목록, 클릭 시 flyTo 지원.
- `frontend/src/hooks/useOSINTSummary.ts`: 폴링 데이터에서 요약 메트릭 계산.

**M7: 피드 + 선도 탭**
- `frontend/src/components/osint/FeedTab.tsx`: 실시간 이벤트 스트림 (전체/군사/정보/인프라/환경 필터), 클릭 시 flyTo.
- `frontend/src/components/osint/FreshnessTab.tsx`: 빠른/느린 갱신 그룹별 데이터 소스 선도 표시 (정상/지연/오류 상태 표시).

**M8: 빌드 검증**
- `npx tsc --noEmit`: 0 errors
- `npm run build`: 성공 (Turbopack, 2.8s)
- `uv run python -m py_compile seed_generator.py`: 통과
