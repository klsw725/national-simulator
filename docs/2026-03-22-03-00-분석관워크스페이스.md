## 변경 요약

### M1: 검색/필터 API
- `backend/app/routers/scenario.py` 수정: GET /api/scenario에 q, status, region, created_after/before, sort, order, limit, offset 파라미터 추가. ILIKE 전문 검색. total 카운트 반환. 페이지네이션.

### M2: 비교 API
- `backend/app/services/scenario_comparator.py` 신규: ScenarioComparator 서비스
  - 두 시나리오의 행위자, 액션 수, 지정학 이벤트 비교 + diff 계산
- `backend/app/routers/scenario.py` 수정: GET /api/scenario/{id1}/compare/{id2} 엔드포인트

### M3: 프론트엔드 검색/필터 UI
- `frontend/src/components/simulation/ScenarioSearch.tsx` 신규: 검색 바 + 상태 필터 + 정렬 옵션 + debounce 300ms
- `frontend/src/lib/gatewayApi.ts` 수정: searchScenarios, compareScenarios, getDashboard 함수 추가
- `frontend/src/hooks/useSimulation.ts` 수정: filteredScenarios 상태 추가
- `frontend/src/components/simulation/SimulationPanel.tsx` 수정: 목록 탭에 ScenarioSearch 통합

### M4: 비교 뷰
- `frontend/src/components/simulation/ComparisonView.tsx` 신규: 시나리오 A/B 선택 → 나란히 비교
  - ScenarioCard (행위자, 액션, 지정학 카운트) + DiffSection (증가=녹색, 감소=빨강)

### M5: 대시보드
- `backend/app/routers/dashboard.py` 신규: GET /api/dashboard (상태별/지역별 분포, 최근 활동, 실행 중 시뮬레이션)
- `backend/app/main.py` 수정: dashboard 라우터 등록
- `frontend/src/components/simulation/AnalystDashboard.tsx` 신규: 통계 카드 + 지역별 분포 + 실행 중 시뮬레이션 + 최근 활동 피드 (30초 자동 갱신)
- `frontend/src/components/simulation/SimulationPanel.tsx` 수정: "비교" + "대시보드" 탭 추가
