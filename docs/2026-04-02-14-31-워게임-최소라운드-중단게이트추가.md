# 작업 요약: 워게임 진행 방향 결정 최소 라운드 게이트 추가

## 사용자 프롬프트

```text
1
```

## 배경

- 중단 조건을 완화한 뒤에도 특정 시나리오에서는 1라운드 이벤트 누적이 커서 `wargame:paused:round_1`가 계속 발생했다.
- 사용자가 원하는 흐름은 최소 몇 라운드 진행 후 다음 진행 방향을 결정하는 것이다.

## 변경 사항

- `backend/app/services/geopolitics_interactive.py`
  - `GAME_MASTER` 모드에서 `round_result["round"] < 2`이면 pause 평가를 아예 하지 않도록 변경
  - 즉 1라운드 종료 직후에는 decision point를 만들지 않음

## 기대 효과

- 최소 2라운드 이후부터만 geopolitics direction decision point가 생성된다.
- 1라운드 이벤트 밀도가 높아도 너무 이른 개입이 발생하지 않는다.

## 검증

- `python -m py_compile backend/app/services/geopolitics_interactive.py`
