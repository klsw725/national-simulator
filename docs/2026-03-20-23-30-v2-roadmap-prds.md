## 의존성 트리

```
PostgreSQL + PostGIS (기반)
  ├── stix2 온톨로지 표준화
  │     └── 스키마 버전관리
  ├── Entity Resolution
  ├── Action Layer
  └── 스냅샷 브랜칭

OASIS Platform 서브클래싱 (독립)
  └── 지정학 시나리오 엔진
```

## 각 PRD 핵심 내용

- **v2-postgresql-postgis**: SQLite → PG + PostGIS 마이그레이션. asyncpg 전환, Alembic 도입, 공간 인덱스
- **v2-stix2-ontology**: 2-Tier 온톨로지 (원시 관측 + STIX-aligned 해소 엔티티). x-vessel, x-aircraft 커스텀 SDO
- **v2-entity-resolution**: Gotham 패턴 비파괴적 해소. 정확/퍼지/공간 매칭, 수동 검토 큐
- **v2-action-layer**: PG append-only 이벤트 테이블. 승인 규칙, RBAC, 보상 Action 롤백
- **v2-snapshot-branching**: PG 스키마 격리로 시나리오/라이브 경계 분리. 투영 레이어
- **v2-schema-versioning**: 온톨로지 버전 MAJOR.MINOR.PATCH. Breaking 변경 자동 감지
- **v2-oasis-platform-subclassing**: GeopoliticsActionType + GeopoliticsPlatform 서브클래스. MiroFish ~20줄 수정
- **v2-geopolitics-scenario-engine**: 국가 행위자 상태 전이 모델. OASIS 양방향 연동 (지정학 결정 → 소셜 반응 → 여론 피드백)
