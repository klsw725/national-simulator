### 로그 포맷

```
2026-03-31 06:00:00 INFO     [a3f2b1c0] app.middleware: GET /api/health → 200 (12ms)
```

### 동작
- 인바운드 `X-Request-ID` 헤더 존재 시 재사용, 없으면 자동 생성 (8자 UUID)
- `ContextVar`로 전파 → 모든 `logger.info/warning/error` 호출에 자동 포함
- 응답 헤더 `X-Request-ID`로 반환

## Phase 19: Alembic DB 마이그레이션

### 설치

```bash
uv add alembic
```

### 구조

```
backend/
├── alembic.ini
├── alembic/
│   ├── env.py (settings.database_url 사용, target_metadata=None)
│   └── versions/
│       └── 001_initial_schema.py (기존 inline DDL 전체)
```

### 설계 결정
- SQLAlchemy 모델 미사용 → `target_metadata=None` (autogenerate 불가)
- 마이그레이션은 raw SQL (`op.execute(...)`)
- `database.py`의 inline SCHEMA는 fallback으로 유지 (운영 환경 안정성)
- 운영 배포 시: `uv run alembic upgrade head` 선 실행 → 앱 시작
