## 변경 사항

### 신규 파일
- `external/mirofish-backend/scripts/test_geopolitics_e2e.py` — 3개 국가(US, CN, PH) 3라운드 E2E 테스트. 9개 액션 실행, 이벤트 개수/액션 타입/라운드 번호/콜백 검증. OASIS 설치 시 Platform 호환성 검증.

### 수정 파일
- `external/mirofish-backend/requirements.txt` — `duckduckgo-search>=7.0.0`, `camel-ai[tools]>=0.2.78` 추가
- `external/mirofish-backend/app/platforms/geopolitics_platform.py` — `event_callback` 파라미터 추가. `_record_event()`에서 콜백 호출 (이벤트 영속화용).
- `external/mirofish-backend/scripts/run_twitter_simulation.py` — `--geopolitics-enabled` 플래그 추가. GeopoliticsPlatform 초기화 + `geopolitics_events.jsonl` 파일 저장.
- `external/mirofish-backend/app/services/simulation_runner.py` — `geopolitics_enabled` 파라미터 + subprocess `--geopolitics-enabled` 전달
- `external/mirofish-backend/app/api/simulation.py` — `geopolitics_enabled` API 파라미터 → SimulationRunner 전달
- `backend/app/clients/mirofish.py` — `geopolitics_enabled` 파라미터 추가
- `backend/app/services/simulation_orchestrator.py` — `geopolitics_enabled` → MiroFish start_simulation 전달

### 핵심 설계
1. **Regression 안전**: tools_enabled/geopolitics_enabled 기본값 False → 기존 Twitter 시뮬레이션 코드 경로 미변경
2. **이벤트 영속화**: 콜백 패턴으로 subprocess 내 이벤트를 JSONL 파일에 저장. 오케스트레이터가 후속 수집 가능.
3. **OASIS 미설치 fallback**: `_HAS_OASIS=False`일 때 GeopoliticsPlatform은 object 상속으로 독립 동작
