# 작업 요약: 워게임 진행 방향 결정 중단 조건 완화

## 사용자 프롬프트

```text
근데 원래 계획은 라운드 끝나고 다음 진행 방향을 결정해야 하는데 라운드 끝나기 전에 발생하는것 같다?
2로 가자
```

## 배경

- 기존 game master 모드 중단 조건은 라운드 결과 이벤트 중 magnitude가 threshold 이상인 이벤트가 하나만 있어도 즉시 decision point를 생성했다.
- 체감상 라운드가 막 끝난 직후 매번 결정을 요구하는 것처럼 보여 중단 빈도가 과도했다.

## 변경 사항

- `backend/app/services/geopolitics_interactive.py`
  - `should_pause()`의 game master 분기 수정
  - 이제 다음 조건에서만 중단한다.
    - cascade event가 존재할 때
    - threshold 이상 고강도 이벤트가 2개 이상일 때
    - 또는 라운드 내 이벤트 magnitude 누적합이 `threshold * 2` 이상일 때

## 의도

- 단일 고강도 이벤트 1건만으로는 바로 방향 결정을 띄우지 않고,
- 라운드 내 중요 이벤트가 누적되었을 때만 개입하도록 완화했다.

## 검증

- `python -m py_compile backend/app/services/geopolitics_interactive.py`
