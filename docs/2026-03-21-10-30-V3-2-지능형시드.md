# V3-2 지능형 시드 생성 (M1-M3)

> 날짜: 2026-03-21
> 프롬프트: `go` (prd-next 추천 V3-2 M1-M3 수락)

## 변경 사항

### 수정 파일
- `backend/app/database.py` — `scenario_observations` 테이블 + 인덱스 추가 (scenario_id, observation_id, used_in_seed)
- `backend/app/services/seed_generator.py`:
  - `_get_resolver_context(bbox)`: bbox 내 observations 조회 → resolution_decisions JOIN stix_objects (confidence ≥ 0.7, 최대 20개). ST_DWithin(10km) 근접 엔티티 쌍 조회 (최대 10개).
  - `generate()`: resolver 컨텍스트를 SEED_GENERATION_PROMPT에 "엔티티 해소 결과" + "근접 엔티티 관계" 섹션으로 주입. 메타데이터에 resolved_entity_count, used_observation_ids 추가.
- `backend/app/models/seed.py` — SeedMetadata에 web_search_count, resolved_entity_count, used_observation_ids 필드 추가
- `backend/app/routers/simulation.py`:
  - `generate_seed()`: 시드 생성 후 used_observation_ids를 scenario_observations 테이블에 기록
  - `GET /api/scenario/{id}/observations` API 추가 (감사 트레일 조회)

### 핵심 설계
1. **하위 호환성**: observations가 없으면 빈 컨텍스트 → 기존 SB 데이터만으로 시드 생성 (변경 없음)
2. **Graceful fallback**: _get_resolver_context() 실패 시 경고 로그만 남기고 계속
3. **성능**: GIST 인덱스 활용, bbox 사전 필터링, LIMIT 200/20/10으로 쿼리 제한
4. **M4(프론트엔드 시드 미리보기)**: 향후 작업으로 분리
