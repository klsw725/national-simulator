## Phase 14: DB 트랜잭션 관리 도입

### 변경 내용

`database.py`에 `get_db_tx()` 트랜잭션 의존성 추가. 다단계 쓰기 엔드포인트에만 적용.

```python
async def get_db_tx():
    pool = get_pool()
    async with pool.acquire() as conn:
        async with conn.transaction():
            yield conn
```

### 적용 대상 (5개 엔드포인트)

| 라우터 | 엔드포인트 | 쓰기 패턴 |
|--------|-----------|-----------|
| seed.py | `generate_seed` | INSERT seeds + INSERT scenario_observations + UPDATE scenarios |
| simulation_run.py | `start_simulation` | INSERT simulation_results + UPDATE scenarios |
| simulation_run.py | `continue_pipeline` | 다수 UPDATE/INSERT across decision_points, seeds, scenarios, simulation_results |
| simulation_interactive.py | `pause_simulation` | UPDATE simulation_results + UPDATE scenarios |
| simulation_interactive.py | `resume_simulation` | UPDATE simulation_results + UPDATE scenarios |

### 유지 항목 (get_db)
- 읽기 전용 엔드포인트
- 단일 테이블 쓰기 엔드포인트
- 백그라운드 태스크 (`_generate_decision_options` 등) — `get_pool()` 직접 사용
