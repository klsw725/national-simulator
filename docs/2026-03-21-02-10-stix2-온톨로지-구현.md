# STIX2 온톨로지 레이어 구현 기록

## 사용자 프롬프트
1. TASK: Implement the stix2 ontology layer for osint-simulator — custom SDOs, PG table, validator, and repository (v2-stix2-ontology, all 4 milestones).

2. EXPECTED OUTCOME:
- 6 custom STIX Domain Objects defined with stix2 library
- PG `stix_objects` table created on startup
- StixValidator for validating STIX objects
- Tier2Repository for CRUD on stix_objects table
- `uv run python -c "import sys; sys.path.insert(0, '.'); from app.main import app; print('OK')"` succeeds
- Custom SDOs can be instantiated: `XVessel(name="test", mmsi="123456789")`

3. REQUIRED TOOLS: Read, Write, Edit, Bash, Glob

4. MUST DO:
- Step 1: Read existing files for patterns (`database.py`, `config.py`, `pyproject.toml`, `main.py`)
- Step 2: Add `stix2>=3.0.0` and run `uv sync`
- Step 3: Create `app/ontology/__init__.py`
- Step 4: Create `app/ontology/custom_sdo.py` with 6 custom SDOs
- Step 5: Add `stix_objects` table/indexes to `database.py` SCHEMA
- Step 6: Create `app/ontology/validator.py`
- Step 7: Create `app/ontology/tier2_repository.py`
- Step 8: Run SDO/validator/app import verification commands
- Step 9: Create this work log file

5. MUST NOT DO:
- No Alembic, no STIX CRUD API endpoints, no JSONB, no ontology import in `main.py`
- No changes outside requested files (except newly created ontology files/docs)

- `backend/pyproject.toml`
  - 의존성에 `stix2>=3.0.0` 추가

    - `XAircraft` (`x-aircraft`)

  - `StixValidationError` 예외 정의
  - `StixValidator.validate()`/`serialize()` 구현

- `backend/app/ontology/tier2_repository.py`
  - `Tier2Repository` 구현
  - `create`, `get_by_stix_id`, `list_by_type`, `delete` 및 `_row_to_dict` 제공
