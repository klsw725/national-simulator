# v12 spec 검증 수정

- 시간: 2026-04-07 05:18 UTC
- 사용자 프롬프트: `@docs/specs/v12-geopolitical-intelligence-platform/spec.md 이거에 맞게 잘 구현되어 있는지 검증해` / `수정해`

## 변경 사항

### 백엔드
- LangGraph 시뮬레이션 개입 지점을 `interrupt()` 기반으로 변경하여 사용자 결정이 네이티브 resume 흐름으로 전달되도록 수정.
- `Command(resume=...)` 기반 결정 재개 로직을 추가.
- `SimulationState`에 `messages` 필드를 추가.
- 사용자 개입 결정이 다음 라운드 액션에 반영되도록 override 상태 직렬화/복원 경로를 보강.
- 중복 `report_ready` 발행을 제거.

### 프론트엔드
- `useLiveSimulation`의 HTTP 폴링을 제거하고 SSE 스트림 기반 파생 상태로 교체.
- `useSimulation`의 상태 추적을 폴링에서 SSE 스트림으로 전환.
- `useWargame`의 폴링 fallback을 제거하고 SSE 중심으로 정리.
- v2 워게임 결정 제출이 `/decide_v2`를 사용하도록 수정.
- `LiveActionFeed`를 지정학 액션 타입 기준으로 렌더링하도록 수정.

## 검증

- `frontend`: `npm run build` 통과
- `simulation-service`: `uv run python -m py_compile ...` 통과

## 메모

- Python LSP의 missing import 진단은 로컬 분석 환경 설정 문제로 남아 있었고, 실제 `uv run` 컴파일은 성공했다.
