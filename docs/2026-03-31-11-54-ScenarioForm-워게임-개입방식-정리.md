# ScenarioForm 워게임 개입 방식 UI 정리

## 프롬프트

> 시뮬레이션 고급 탭에 지정학적 이벤트 발생 활성 시 나오는 선택란이 이제 무의미하지 않나....? → 그래

## 문제

기존 `ScenarioForm`의 고급 설정에는 다음 UX가 남아 있었음:

- `지정학적 이벤트 활성/비활성` 토글
- 활성 시 `지정학 개입 모드` 선택

하지만 현재 구조에서는:

- `wargame_enabled`가 기본적으로 `true`
- 워게임 모드에서 지정학 엔진은 사실상 항상 활성화
- 레거시 interactive geopolitics 모드는 제거됨

따라서 `geopolitics_enabled` 토글은 UX적으로 중복/무의미해짐.

## 수정

`frontend/src/components/simulation/ScenarioForm.tsx`

- `geopolitics_enabled` 상태/토글 UI 제거
- `geopolitics_mode` 기본값을 `game_master`로 변경
- 고급 설정에 `워게임 개입 방식` 선택만 남김
  - `시나리오 방향 결정` (`game_master`)
  - `특정 국가 역할 수행` (`actor_role`)
- `actor_role`일 때만 `역할 국가` 입력 노출
- 제출 시:
  - `geopolitics_enabled: true` 고정
  - `geopolitics_mode`는 선택값 사용
