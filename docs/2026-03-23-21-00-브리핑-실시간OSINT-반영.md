# 브리핑 생성 시 현재 OSINT 데이터 반영

> 날짜: 2026-03-23
> 관련: briefing_generator.py, routers/simulation.py

## 프롬프트

```
보고서를 보니까 옛날 데이터를 쓰는 것 같던데 데이터 가져올 때 현재 날짜를 기준으로 가져오고 있는거야?
→ 브리핑 보고서에서 확인
→ 원인 분석 + 수정
```

## 문제

`BriefingGenerator.generate()`가 DB에 저장된 시드 텍스트만 사용하여 브리핑을 생성.
시드는 시나리오 생성 시점에 한 번만 ShadowBroker에서 가져오므로, 이후 브리핑에는 과거 OSINT 데이터가 반영됨.

## 변경 사항

### 수정 파일 (2개)

- `backend/app/services/briefing_generator.py`
  - `__init__`: `sb_client: ShadowBrokerClient | None` 파라미터 추가
  - `_collect_current_osint(bbox)`: SB fast/slow 데이터 실시간 조회 → bbox 필터 → 군함/항공기/UAV/GDELT/뉴스 요약
  - `BRIEFING_PROMPT`: `{current_osint_section}` 플레이스홀더 + "## 7. 현재 상황 대비 변화" 섹션 추가
  - `generate()`: `region_bbox` 조회 → `_collect_current_osint()` 호출 → 시드 생성 시각 라벨링 → 프롬프트 주입

- `backend/app/routers/simulation.py`
  - `generate_briefing()`: `request: Request` 파라미터 추가, `sb_client`를 `BriefingGenerator`에 전달

### 동작 방식

1. 브리핑 생성 시 시나리오의 `region_bbox`를 조회
2. ShadowBroker fast/slow API에서 현재 실시간 OSINT 데이터 수집
3. bbox로 필터링하여 해역 내 자산 수, GDELT 헤드라인, 최신 뉴스 요약
4. LLM 프롬프트에 "현재 OSINT 상황" 섹션으로 주입
5. LLM이 "## 7. 현재 상황 대비 변화"에서 시드 시점과 현재를 비교 분석

### 하위 호환성

- `sb_client=None` 기본값 → SB가 없으면 기존과 동일하게 동작 (current_osint_section이 빈 문자열)
- SB 연결 실패 시 graceful degradation → "(현재 OSINT 데이터 수집 실패)" 메시지
