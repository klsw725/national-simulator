# 시뮬레이션 완료 후 화면 미전환 버그 수정

**날짜**: 2026-04-07
**프롬프트**: "시뮬레이션 설정하고, 끝났을때 화면이 안 바뀐다"

## 문제

시뮬레이션이 정상 완료(DB: status=completed, 10/10 라운드)되었지만, 프론트엔드 WarRoom에서 디브리프(완료 요약) 화면이 표시되지 않았다. 진행 중 오버레이만 사라지고 빈 화면이 남는 현상.

## 근본 원인

두 가지 버그가 중첩:

### 1. DebriefView가 v2 모드에서 렌더링 차단 (주범)

`WarRoom.tsx` 289행에서 DebriefView 렌더링 조건이 `!useV2 && wargame.showDebrief`로 되어 있었으나, `useV2`의 기본값이 `true`이므로 이 조건은 **항상 false**. v2 모드(기본값)에서 DebriefView가 절대 나타나지 않았다.

### 2. useSimulationStream에서 REPORT_READY 시 phase 미갱신

`useSimulationStream.ts`의 리듀서에서 `REPORT_READY` 이벤트 수신 시 `status`만 "completed"로 변경하고 `phase`는 갱신하지 않았다. 이로 인해 WarRoom의 `activePhase`가 "simulating"에 머물러 UI 상태 판단이 부정확했다.

## 변경 파일

| 파일 | 변경 내용 |
|------|-----------|
| `frontend/src/components/wargame/WarRoom.tsx` | DebriefView 렌더링 조건에서 `!useV2` 제거 → `wargame.showDebrief`만으로 판단 |
| `frontend/src/hooks/useSimulationStream.ts` | `REPORT_READY` 리듀서에서 `phase: "confirmation"` 추가 |

## 수정 후 동작

```
시뮬레이션 완료
  → SSE "report_ready" 이벤트 수신
  → useSimulationStream: status="completed", phase="confirmation"
  → useWargame: polling으로 wargame_status 확인 → isComplete=true, showDebrief=true
  → WarRoom: wargame.showDebrief=true → DebriefView 렌더링 ✅
```
