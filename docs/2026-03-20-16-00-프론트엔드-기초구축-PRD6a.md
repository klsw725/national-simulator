| 파일 | 역할 |

| `src/hooks/useImperativeSource.ts` | Imperative GeoJSON source update for MapLibre |
| `src/lib/ThemeContext.tsx` | Dark theme provider (MVP: dark only) |
| `src/types/dashboard.ts` | Ship, LiveDataFast, LiveDataSlow, BackendStatus, PollingState |

### 아키텍처 결정
- **API 프록시**: 브라우저 → Next.js `/api/*` → Gateway `:4000` (CORS 우회)
- **ship 아이콘**: canvas로 동적 생성 (yellow=군용, red=화물/유조, blue=기타)
- **클러스터링**: zoom < 4에서 클러스터 원, zoom >= 4에서 개별 아이콘
- **초기 뷰**: 남중국해 (lng:115, lat:15, zoom:4)
