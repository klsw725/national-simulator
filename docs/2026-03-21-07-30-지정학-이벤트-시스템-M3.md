## 변경 사항

### events.py — CASCADE_RULES 추가

- 이벤트가 다른 이벤트를 트리거하는 조건부 연쇄 규칙:
  - sanction_impose → resource_level ≤ 0.4이면 trade_restriction 보복
  - military_movement → threat ≥ 0.5이면 military_exercise 대응, ≥ 0.8이면 counter-deployment
  - military_exercise → threat ≥ 0.6이면 diplomatic_statement 항의
  - trade_restriction → domestic_pressure ≥ 0.6이면 diplomatic_statement
- `MAX_CASCADE_DEPTH = 3` — 무한 재귀 방지
- `CASCADE_DECAY = 0.7` — 각 연쇄 단계마다 magnitude 감쇠

### engine.py — 연쇄 이벤트 처리 + 멀티 라운드

- `apply_event_with_cascade(event, depth)` — 이벤트 적용 후 CASCADE_RULES 평가, 조건 충족 시 후속 이벤트 재귀 생성 (depth ≤ MAX_CASCADE_DEPTH)
- `run_round()` 확장 — cascade_events를 결과에 포함
- `run_simulation(rounds)` — N 라운드 실행, 전체 타임라인 + 최종 상태 반환
