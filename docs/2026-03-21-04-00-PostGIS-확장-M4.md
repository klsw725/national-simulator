## 변경 사항

### backend/app/database.py

1. **PostGIS 확장 활성화** — SCHEMA 최상단에 `CREATE EXTENSION IF NOT EXISTS postgis;` 추가
2. **observations 테이블 생성 (Tier 1)** — 2-Tier 온톨로지 아키텍처의 원시 관측 저장소
   - `id TEXT PRIMARY KEY`
   - `source_type TEXT NOT NULL` — 'ship', 'flight', 'satellite', 'gdelt'
   - `source_id TEXT NOT NULL` — MMSI, ICAO24, NORAD ID 등
   - `raw_data TEXT NOT NULL` — ShadowBroker 원본 JSON
   - `geom geometry(Point, 4326)` — PostGIS 공간 컬럼 (WGS84)
   - `observed_at TEXT NOT NULL` — 관측 시각
   - `created_at TEXT NOT NULL`
3. **공간 인덱스** — `idx_observations_geom USING GIST(geom)` — ST_DWithin, ST_Intersects 등 공간 쿼리 지원
4. **보조 인덱스** — `idx_observations_source(source_type, source_id)`, `idx_observations_time(observed_at)`

## 잠금 해제

- v2-entity-resolution 전체 마일스톤 시작 가능 (공간 근접 매칭 포함)
