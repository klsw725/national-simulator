## 변경 사항

### M1: 행위자 상태 모델 (geopolitics/actors.py 신규)

- `GeopoliticalActorState` 데이터클래스:
  - 동적 상태: threat_perception, domestic_pressure, resource_level (0.0–1.0)
  - 목표/제약: Objective(name, priority), Constraint(name, hard/soft)
  - 관계: allies[], adversaries[]
  - 직렬화: to_dict() / from_dict() — JSON 호환
  - clamp_state() — 값 범위 보장

### M2: 상태 전이 엔진 (geopolitics/engine.py 신규)

- `DecisionEngine` 클래스:
  - `add_actor()` / `get_actor()` — 행위자 관리
  - `apply_event(event)` — 이벤트의 영향을 대상 행위자에 적용. 동맹/적대 관계에 따라 영향 크기 조절 (동맹 0.3x, 적대 1.5x)
  - `decide_actions()` — 전체 행위자의 의사결정 실행:
    - 고위협(≥0.6) + 자원 충분 → military_movement
    - 저자원(≤0.3) → trade_restriction
    - 고압(≥0.8) → diplomatic_statement
    - 저위협(≤0.2) + 동맹 → treaty_sign
  - `run_round()` — decide → apply → summary 반환
  - 제약 조건 검증: hard constraint "no_military" → 군사 행동 차단

### M2: 이벤트 시스템 (geopolitics/events.py 신규)

- `GeopoliticsEvent` 데이터클래스: event_type, source_actor_id, target_actor_ids, magnitude
- `PROPAGATION_RULES` — 이벤트 타입별 상태 변경 규칙:
  - military_movement → threat+0.15, pressure+0.05
  - sanction_impose → resource-0.20, pressure+0.15
  - treaty_sign → threat-0.10, pressure-0.05
