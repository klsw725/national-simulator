### 설계 결정

- OSINT 데이터 1회 수집: SB API 호출을 1회만 수행하고 3개 LLM 호출에 공유
- 관점별 프롬프트: 기존 SEED_GENERATION_PROMPT에 관점 지시를 append
- temperature 0.6: 관점 차이를 위해 기존 0.4보다 약간 높게 설정
- confidence 계산: GDELT tension_score + vessels_count 기반 (군사 데이터가 풍부할수록 군사 관점 confidence↑)
