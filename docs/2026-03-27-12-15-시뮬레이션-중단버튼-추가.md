# 시뮬레이션 중단 버튼 UI 추가

## 프롬프트

```
근데 진행중인 시뮬레이션을 멈추는 방법은 없는거지?
UI에 버튼 추가해 호출을 할수가 없잖니
```

## 원인

- 백엔드에 `POST /{scenario_id}/simulation/pause` API 존재
- `InteractiveSimulationView`에 일시정지 버튼 있지만 `tab === "interactive"` 탭에서만 접근 가능
- 시뮬레이션 진행 중 메인 화면(`PipelineProgress` + `IntermediateResults`)에는 중단 수단 없음

## 변경 사항

### `frontend/src/components/simulation/SimulationPanel.tsx`

- `StopCircle` 아이콘, `pauseSimulation` API import 추가
- 파이프라인 진행 중 화면에 빨간색 "중단" 버튼 추가
- 클릭 시 `confirm` 확인 후 `pauseSimulation(scenarioId)` 호출
- 성공 시 시나리오 목록 새로고침
