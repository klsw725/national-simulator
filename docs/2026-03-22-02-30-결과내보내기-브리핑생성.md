## 변경 요약

### M1: 데이터 내보내기 API
- `backend/app/services/data_exporter.py` 신규: DataExporter 서비스
  - `export_scenario_json()`: 시나리오 전체 데이터 (시나리오+시드+결과+지정학+관측 카운트)
  - `export_actions_csv()`: 시뮬레이션 액션 CSV (round, platform, actor, action_type, content, timestamp)
  - `export_observations_csv()`: 관측 데이터 CSV (source_type, source_id, lat, lng)
  - `export_geopolitics_csv()`: 지정학 이벤트 CSV
  - `export_report_markdown()`: MiroFish 보고서 마크다운
- `backend/app/routers/simulation.py` 수정: 5개 GET 엔드포인트 추가
  - `/export?format=json|csv`, `/export/observations`, `/export/geopolitics`, `/export/report`
  - Content-Disposition 헤더로 파일 다운로드

### M2: AI 브리핑 생성기
- `backend/app/services/briefing_generator.py` 신규: BriefingGenerator
  - 시드+결과+지정학+보고서를 LLM에 입력 → 7개 섹션 구조화된 브리핑 마크다운 생성
  - temperature=0.3, max_tokens=4096
- `backend/app/database.py` 수정: briefings 테이블 추가 (id, scenario_id, content, version, created_at, updated_at)
- `backend/app/routers/simulation.py` 수정: 3개 브리핑 엔드포인트 추가
  - POST `/briefing/generate`, GET `/briefing`, PUT `/briefing`

### M3: 프론트엔드 내보내기 UI
- `frontend/src/components/simulation/ExportPanel.tsx` 신규: 내보내기 탭
  - 5개 다운로드 버튼 (JSON, CSV, 관측, 지정학, 보고서)
  - AI 브리핑 생성 버튼 + 불러오기 버튼
- `frontend/src/lib/gatewayApi.ts` 수정: 6개 export/briefing API 함수 추가
- `frontend/src/components/simulation/SimulationPanel.tsx` 수정: "내보내기" 탭 추가 (완료 시 표시)

### M4: 브리핑 편집기
- `frontend/src/components/simulation/BriefingEditor.tsx` 신규: 마크다운 편집기
  - 편집/미리보기 모드 토글
  - 저장 (PUT /briefing) + 내보내기 (마크다운 다운로드)
  - 버전 표시, 변경 감지
