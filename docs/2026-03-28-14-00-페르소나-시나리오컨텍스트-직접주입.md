# 페르소나 생성에 시나리오 컨텍스트(시드 문서) 직접 주입

**날짜**: 2026-03-28
**프롬프트**: "페르소나 생성시에도 웹 결과를 사용하는거지? 현재 이란-미국 전쟁이 반영되는지가 알고 싶은거든 / 어떻게 생각하는가? / static 하게 넣는건 아닌거지?"

## 문제

페르소나 생성 시 시드 문서(실시간 OSINT + 웹 검색)가 5단계 변환(seed → ontology → graph → Zep 검색 → context)을 거치면서 희석됨. "이란-미국 전쟁" 같은 시사적 맥락이 페르소나에 반영되지 않아, 에이전트가 행동할 이유를 알지 못함.

## 변경 사항

### 1. `oasis_profile_generator.py`
- `__init__`에 `self.scenario_context: str = ""` 필드 추가
- `generate_profiles_from_entities()`에 `scenario_context` 파라미터 추가
- `_build_entity_context()`에서 시나리오 컨텍스트를 context 최상단에 추가:
  ```
  ### 현재 시나리오 배경 (실시간 OSINT 및 뉴스)
  [시드 문서 내용 — 군함 배치, 항공기 활동, 웹 검색 뉴스 등]
  ```

### 2. `simulation_manager.py`
- `prepare_simulation()`에서 `generator.generate_profiles_from_entities()`에 `scenario_context=document_text` 전달

## 데이터 흐름 (수정 후)

```
매 시뮬레이션 실행 시점 (static 아님)
    ↓
ShadowBroker → 실시간 OSINT (군함, 항공기, 위성...)
DuckDuckGo → 최신 뉴스 ("Iran US military tension"...)
    ↓
LLM → 시드 문서 (document_text) 생성
    ↓
MiroFish prepare → document_text를 profile generator에 전달 ← 새로 추가
    ↓
_build_entity_context()에서 "### 현재 시나리오 배경"으로 context 최상단에 삽입
    ↓
이란 페르소나 LLM이 보는 context:
  "현재 호르무즈 해협에 미국 항모전단 배치, 이란 해협 통제 선언..."
    ↓
페르소나: "이란은 현재 미국과 군사적 대치 중이며..."
    ↓
시뮬레이션 런타임에서 이란 에이전트가 자연스럽게 공식 성명 발표
```

## 기존 코드 영향
- `scenario_context` 기본값 = `""` → 기존 호출에 영향 없음
- `scenario_context`가 비어 있으면 context에 아무것도 추가되지 않음
