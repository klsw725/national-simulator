# 에이전트 런타임 페르소나 필수 행동 규칙 추가

**날짜**: 2026-03-28
**프롬프트**: "이란이 의견을 내보내지 않을수가 없는데 의견이 없는게 이상하다. 시드에 웹 검색을 시켰는데도 이런게 발생"

## 문제 진단

프롬프트가 3단계로 나뉘어 있었으며, 이전 수정은 ①②만 해결:

1. `SIMULATION_REQUIREMENT` (온톨로지 생성 시) — 수정 완료
2. `simulation_config_generator` (에이전트 프로필 생성 시) — 수정 완료
3. **`GEOPOLITICS_PERSONA_PROMPT` (에이전트 런타임 행동 결정 시) — 미수정 ← 근본 원인**

이란은 엔티티로 존재(RegionalPower)했지만, 매 라운드 행동을 결정할 때 보는 `GEOPOLITICS_PERSONA_PROMPT`에서 DO_NOTHING이 동등한 선택지로 제시되어 LLM이 "안전한" DO_NOTHING을 반복 선택.

## 변경 사항

**파일**: `external/mirofish-backend/app/platforms/geopolitics.py`

`GEOPOLITICS_PERSONA_PROMPT`에 【필수 행동 규칙】 섹션 추가:
- 해상 안보 위기 시 완전한 침묵은 비현실적 → 공식 입장 표명 필수
- 첫 번째 행동으로 DO_NOTHING 금지
- DO_NOTHING은 다른 적극적 행동 수행 후에만 가능
- 타국 성명 발표 시 QUOTE_POST 우선 고려
- 국제기구는 최소 "상황 주시" 성명 필수

## 수정된 프롬프트 계층 (전체 정리)

| 계층 | 파일 | 적용 시점 | 상태 |
|---|---|---|---|
| ① SIMULATION_REQUIREMENT | simulation_orchestrator.py | 온톨로지 생성 | 수정 완료 |
| ② 에이전트 프로필 생성 | simulation_config_generator.py | 프로필 생성 | 수정 완료 |
| ③ 런타임 페르소나 | geopolitics.py | 매 라운드 행동 결정 | **이번에 수정** |
