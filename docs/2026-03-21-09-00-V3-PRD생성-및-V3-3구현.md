## 2. V3-3 구현 (M1-M4 완료)

### 변경된 파일

**백엔드:**
- `backend/app/models/scenario.py` — SimulationParams 모델 추가 (platform, simulation_hours, simulation_requirement, geopolitics_enabled). ScenarioCreate, ScenarioResponse에 simulation_params 필드 추가.
- `backend/app/database.py` — scenarios 테이블에 simulation_params TEXT 컬럼 추가 (ALTER TABLE, DEFAULT '{}')
- `backend/app/routers/scenario.py` — create_scenario에서 simulation_params 저장. _row_to_response에서 파싱하여 반환. SimulationParams import 추가.
- `backend/app/services/simulation_orchestrator.py` — run_pipeline/run_from_checkpoint에 simulation_params 전달. _step_ontology: simulation_requirement 파라미터화 (None이면 기본값 사용). _step_create_prepare: enable_twitter/enable_reddit 파라미터화. _step_run_simulation: platform + simulation_hours 파라미터화. SimulationParams import 추가.
- `backend/app/clients/mirofish.py` — start_simulation에 simulation_hours 파라미터 추가 (None이면 미전달). create_simulation에 enable_twitter/enable_reddit 파라미터 추가 (하드코딩 제거).
- `backend/app/routers/simulation.py` — start_simulation과 continue_pipeline에서 simulation_params를 DB에서 조회하여 orchestrator에 전달. checkpoint 모드 시작 시 platform 파라미터화.

**프론트엔드:**
- `frontend/src/types/simulation.ts` — SimulationParams 인터페이스 추가. Scenario와 ScenarioFormData에 simulation_params 필드 추가.
- `frontend/src/components/simulation/ScenarioForm.tsx` — "고급 설정" 접이식 섹션 추가 (platform select, simulation_hours slider, simulation_requirement textarea, geopolitics_enabled 토글).
- `frontend/src/lib/gatewayApi.ts` — createScenario에서 simulation_params를 POST body에 포함.

### 핵심 설계 결정

1. **하위 호환성**: simulation_params가 빈 JSON `{}`이면 SimulationParams 기본값 (twitter, 24h, 기본 프롬프트, geopolitics off)이 적용된다.
2. **simulation_requirement**: None이면 기존 SIMULATION_REQUIREMENT 상수를 사용. 커스텀 값이 있으면 해당 값 사용.
3. **platform → enable_twitter/enable_reddit 매핑**: "twitter" → (true, false), "reddit" → (false, true).
