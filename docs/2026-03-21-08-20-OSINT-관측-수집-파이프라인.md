## 변경 사항

### services/observation_collector.py (신규)

- `ObservationCollector.collect(source_type, bbox, auto_resolve)`:
  1. ShadowBrokerClient.get_fast_data()로 SB 데이터 조회
  2. source_type별 필드 추출 (ships/flights/satellites)
  3. observations INSERT — PostGIS geom은 ST_SetSRID(ST_MakePoint(lng, lat), 4326)
  4. auto_resolve=True이면 각 관측에 대해 Resolver.auto_resolve() 실행
- AGENTS.md 지뢰 준수: ships/flights/satellites는 `lng` 필드 사용
- source_id 추출: ship→mmsi, flight→icao24, satellite→norad_id

### routers/osint.py 수정

- `POST /api/osint/collect?source=ship&auto_resolve=true` — 수집 + 자동 Entity Resolution
- bbox 쿼리 파라미터 지원 (s, w, n, e)
- SB 연결 실패 시 503/504 응답

## 데이터 흐름

```
POST /api/osint/collect?source=ship
  → ShadowBrokerClient.get_fast_data()
  → observations INSERT (PostGIS geom)
  → Resolver.auto_resolve() → resolution_candidates + decisions
  → {collected: N, resolved: M}
```
