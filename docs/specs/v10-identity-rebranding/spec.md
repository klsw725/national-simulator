# OSINT Simulator V10 - Technical Specification

> Version: 10.0.0
> Date: 2026-03-30
> Status: Draft
> Codename: **Ghostfish v10** — Identity Rebranding

---

## 1. Executive Summary

V10은 기능 변경 없이 프로젝트의 표현 정체성을 "해상 안보"에서 "국제정치/지정학 시뮬레이터"로 정렬하는 텍스트 리브랜딩 단계다. LLM 프롬프트, 시드/폴백 문구, 일부 메타데이터/문서의 잔존 용어를 정리해 실제 기능 범위와 사용자 메시지를 일치시키는 데 초점을 둔다. 구조·API·변수명은 유지하며, 최소 라인 변경으로 프레이밍 불일치를 해소하는 것이 목표다.

### V9 → V10 핵심 차이

| V9 | V10 |
|---------|------|
| 인터랙티브 지정학 실행 모델 확장 | 기능 유지 + 정체성/표현 정렬 |
| 런타임 동작/의사결정 흐름 중심 변경 | 텍스트 프롬프트/라벨 중심 변경 |
| 일부 "해상/해역/maritime" 잔존 | "지정학/관심 지역" 표현으로 통일 |
| 시스템 동작 정확도 중심 | 사용자 인식/프롬프트 맥락 정확도 강화 |
