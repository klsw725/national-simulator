# PRD: 프로젝트 정체성 전환 — "해상 안보" → "국제정치/지정학 시뮬레이터"

> Status: In Progress
> Created: 2026-03-30
> Dependencies: 없음 (기존 기능 변경 없이 텍스트만 수정)
> 버전: v10.0

---

## 1. 문제 정의

프로젝트의 실제 기능은 **국제정치/지정학 시뮬레이터**이나, MVP 시절 "해상 긴장 시뮬레이션"으로 출발한 잔재가 코드베이스에 남아 있다.

### 현재 상태

- **실제 기능**: 국가 행위자 간 외교·군사·경제 상호작용 시뮬레이션 (treaty_sign, sanction_impose, diplomatic_statement 등), 20개+ OSINT 데이터 소스, 인과 분석, What-If 분기
- **코드베이스 95%+**: 이미 `geopolitics_*` 변수명, `/api/geopolitics/*` 라우트, "지정학" UI 라벨 사용
- **잔존 문제**: LLM 프롬프트와 일부 폴백 텍스트에 "해상 안보", "해역" 표현이 남아있음. 프론트엔드 메타데이터에 "maritime" 잔존

### 왜 문제인가

1. **LLM 시뮬레이션 품질 저하**: `simulation_requirement` 프롬프트가 "해상 안보 시나리오"로 고정되어 있어, 육지 기반 시나리오(한반도 DMZ, 유럽 국경 분쟁 등)에서 맥락이 안 맞음
2. **사용자 혼란**: 앱 설명이 "maritime intelligence dashboard"인데 실제로는 국제정치 시뮬레이터
3. **시드 생성기 편향**: 폴백 텍스트가 전부 "해역 내 ~미감지"여서, 내륙 시나리오에서 부자연스러운 메시지 표시
