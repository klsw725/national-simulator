# OSINT Simulator V4 - Technical Specification

> Version: 4.0.0
> Date: 2026-03-21
> Status: Draft
> Codename: **Ghostfish v4** — Analyst-in-the-Loop

---

## 1. Executive Summary

V3에서 구축한 자동화 파이프라인(OSINT 수집 → 엔티티 해소 → 시드 생성 → 시뮬레이션 → 지정학 분석)은 **인간 개입 없이 전체가 실행된다.** 분석관은 결과만 볼 수 있고, 과정에 개입할 수 없다.

V4의 핵심 목표: **AI가 분석관에게 핵심 결정 지점에서 선택지를 제시하고, 분석관의 판단을 시뮬레이션에 반영하는 "Analyst-in-the-Loop" 시스템을 구축한다.** 팔란티어 파운드리 AIP의 의사결정 지원 패턴을 OSINT 시뮬레이션 도메인에 적용한다.

### V3 → V4 핵심 차이

| V3 | V4 |
|----|-----|
| 파이프라인이 자동 실행 | 핵심 결정 지점에서 분석관에게 선택지 제시 |
| 시드가 자동 생성 | AI가 3-5개 시드 초안을 제안, 분석관이 선택/수정 |
| 시뮬레이션 결과 사후 확인 | 라운드별 개입 가능 (에이전트 행동 조정, 이벤트 주입) |
| 단일 시나리오 실행 | What-If 분기로 대안 시나리오 탐색 |
| 결과가 UI에서만 확인 | 브리핑 문서 자동 생성 (PDF/Markdown) |
| 분석관이 모든 파라미터를 직접 설정 | AI가 상황에 맞는 권장 설정 제안 |

### 핵심 개념: AI 가이드 의사결정

```
기존 (V3):
  시나리오 생성 → [자동] → 시드 → [자동] → 시뮬레이션 → [자동] → 결과

V4:
  시나리오 생성 → [AI 제안: 3개 시드 옵션] → 분석관 선택
                                                    ↓
                                            시뮬레이션 실행
                                                    ↓
                              [AI 제안: "라운드 5에서 군사 긴장 급등, 개입하시겠습니까?"]
                                                    ↓
                                        분석관: "중국 함대 철수 시나리오 분기"
                                                    ↓
                                         What-If 분기 실행 + 비교
                                                    ↓
                              [AI 제안: "핵심 발견 3개 + 브리핑 초안"]
                                                    ↓
                                        분석관: 수정 → PDF 내보내기
```

### PRD V4-1: AI 가이드 결정 지점

**문제**: 파이프라인의 모든 단계가 자동 실행되어 분석관이 핵심 결정에 개입할 수 없다.

**솔루션**: 파이프라인의 핵심 결정 지점에서 AI가 선택지를 생성하고 분석관에게 제시한다.

**결정 지점**:
1. **시드 선택** — AI가 3-5개의 시드 초안을 생성하여 제시. 각 초안은 다른 관점(낙관적/비관적/중립)을 반영. 분석관이 선택하거나 수정.
2. **행위자 구성** — 온톨로지 생성 후 AI가 행위자 목록과 관계를 제안. 분석관이 행위자 추가/제거/수정.
3. **시뮬레이션 파라미터 권장** — AI가 지역/상황에 맞는 파라미터(platform, hours, rounds)를 권장. 근거와 함께 제시.

**AI 선택지 형식**:
```json
{
  "decision_point": "seed_selection",
  "options": [
    {
      "id": "option_a",
      "label": "군사 긴장 중심",
      "description": "미중 해군 대치에 초점. 군함 배치와 군사 훈련 중심 서술.",
      "confidence": 0.85,
      "reasoning": "최근 GDELT 데이터에서 군사 관련 이벤트 빈도가 40% 증가"
    },
    {
      "id": "option_b",
      "label": "외교 협상 중심",
      "description": "다자간 외교 협상에 초점. ASEAN 중재 역할 포함.",
      "confidence": 0.72,
      "reasoning": "최근 2주간 외교 회담 3건 감지"
    }
  ],
  "recommended": "option_a",
  "allow_custom": true
}
```

**마일스톤**:
- M1: DecisionPoint 모델 + API (백엔드에 결정 지점 저장/조회/응답)
- M2: AI 시드 옵션 생성기 (LLM으로 3-5개 시드 초안 생성)
- M3: AI 파라미터 권장 엔진 (지역/상황 기반 파라미터 제안)
- M4: 프론트엔드 DecisionPointView (선택지 카드 UI + 선택/수정/커스텀 입력)

### PRD V4-2: 인터랙티브 시뮬레이션

**문제**: 시뮬레이션이 시작되면 완료까지 개입할 수 없다. 라운드 중간에 이벤트를 주입하거나 에이전트 행동을 조정할 수 없다.

**솔루션**:
1. **라운드별 일시정지** — 지정된 라운드에서 자동 일시정지. 분석관이 상황을 검토하고 결정.
2. **이벤트 주입** — 분석관이 시뮬레이션 중간에 이벤트를 주입 (예: "미국이 항행의 자유 작전 발표")
3. **What-If 분기** — 현재 라운드에서 분기하여 대안 시나리오 실행. 원본과 병렬 비교.

**인터랙션 모델**:
```
라운드 1-3: [자동 실행]
라운드 4:   [AI 알림: "긴장도 급등 감지. 개입하시겠습니까?"]
            분석관 선택:
            (A) 계속 실행
            (B) 이벤트 주입: "UN 긴급 안보리 소집"
            (C) What-If 분기: "중국 함대 철수"
라운드 5+:  [선택에 따라 분기 실행]
```

**마일스톤**:
- M1: 시뮬레이션 라운드별 일시정지 API (pause_at_round, resume)
- M2: 이벤트 주입 API (시뮬레이션 중간에 ManualAction 주입)
- M3: What-If 분기 엔진 (현재 상태 스냅샷 → 분기 시뮬레이션)
- M4: 프론트엔드 InteractiveSimulationView (라운드별 타임라인 + 개입 UI)
- M5: AI 개입 제안 엔진 (긴장도 급등, 패턴 이상 감지 시 자동 알림)

### PRD V4-3: 결과 내보내기 + 브리핑 생성

**문제**: 시뮬레이션 결과를 내보내거나 공유할 수 없다. 결과가 UI에서만 확인 가능.

**솔루션**:
1. **데이터 내보내기** — JSON, CSV 형식으로 시나리오/결과/관측 데이터 내보내기
2. **브리핑 문서 생성** — AI가 시뮬레이션 결과를 분석하여 전문적인 브리핑 문서 초안 작성
3. **시각화 내보내기** — 그래프/지도를 PNG/SVG로 내보내기

**브리핑 문서 구조**:
```markdown
# 상황 브리핑: [시나리오명]
## 1. 상황 요약 (AI 자동 생성)
## 2. 핵심 발견 (3-5개, AI 추출)
## 3. 행위자 분석
## 4. 시뮬레이션 결과
## 5. 지정학적 함의
## 6. 권장 조치 (AI 제안, 분석관 수정)
## 부록: 데이터 소스, 방법론
```

**마일스톤**:
- M1: 데이터 내보내기 API (JSON/CSV 엔드포인트)
- M2: AI 브리핑 생성기 (LLM으로 시뮬레이션 결과 → 브리핑 초안)
- M3: 프론트엔드 내보내기 UI (다운로드 버튼, 포맷 선택)
- M4: 브리핑 편집기 (AI 초안을 분석관이 수정/확정)

### PRD V4-4: AI 코파일럿

**문제**: 분석관이 시뮬레이션 결과를 스스로 해석해야 한다. AI가 질문에 답하거나 인사이트를 제안하지 않는다.

**솔루션**: 채팅 기반 AI 코파일럿. 현재 시나리오의 컨텍스트를 이해하고 분석관의 질문에 답한다.

**코파일럿 기능**:
- "이 지역에서 최근 1주일간 어떤 군사 활동이 있었나?" → 관측 데이터 검색 + 요약
- "시뮬레이션에서 가장 공격적인 행위자는?" → 액션 분석 + 순위
- "중국이 군사 훈련을 확대하면 어떤 결과가 예상되나?" → What-If 시나리오 제안
- "이 결과를 요약해줘" → 핵심 발견 추출 + 브리핑 초안

**마일스톤**:
- M1: 코파일럿 API (컨텍스트 주입 + LLM 호출 + 도구 사용)
- M2: 시나리오 컨텍스트 빌더 (현재 시나리오의 모든 데이터를 LLM 프롬프트에 구성)
- M3: 코파일럿 도구 (관측 검색, 시뮬레이션 결과 분석, What-If 제안)
- M4: 프론트엔드 CopilotPanel (채팅 UI + 인라인 시각화)

---

### PRD V4-5: 분석관 워크스페이스

**문제**: 시나리오 검색/필터/비교가 없다. 100개 이상의 시나리오를 관리할 수 없다.

**솔루션**:
1. **검색 + 필터** — 시나리오 이름, 지역, 상태, 날짜로 검색/필터
2. **비교 뷰** — 2개 시뮬레이션을 나란히 비교 (타임라인, 행위자 상태, 지정학 결과)
3. **대시보드** — 전체 시나리오 현황 (실행 중/완료/실패, 지역별 분포, 최근 활동)

**마일스톤**:
- M1: 검색/필터 API (시나리오 이름, 지역, 상태, 날짜 범위)
- M2: 비교 API (2개 시나리오 결과 diff)
- M3: 프론트엔드 검색/필터 UI (ScenarioList 확장)
- M4: 프론트엔드 비교 뷰 (ComparisonView 신규 컴포넌트)
- M5: 대시보드 (AnalystDashboard 신규 페이지)

---

### PRD V4-6: 운영 안정성

**문제**: 외부 서비스 장애 시 전체 파이프라인이 실패한다. 에러 복구/재시도가 없다.

**솔루션**:
1. **재시도 + 서킷 브레이커** — MiroFish/ShadowBroker 클라이언트에 지수 백오프 재시도 + 서킷 브레이커
2. **자동 체크포인트 복구** — 파이프라인 실패 시 마지막 성공 체크포인트에서 자동 재시작
3. **헬스체크 대시보드** — 모든 외부 서비스 상태 실시간 모니터링

**마일스톤**:
- M1: HTTP 클라이언트 재시도 + 서킷 브레이커 (MiroFish, ShadowBroker)
- M2: 파이프라인 자동 복구 (실패 시 마지막 체크포인트에서 재시작)
- M3: 서비스 헬스체크 대시보드 (프론트엔드)

## 5. 성공 기준

V4 완료의 정의:

- [ ] AI가 시드 생성 시 3-5개 옵션을 제시하고 분석관이 선택할 수 있다
- [ ] 시뮬레이션 중 라운드별 일시정지 + 이벤트 주입이 가능하다
- [ ] What-If 분기로 대안 시나리오를 병렬 실행/비교할 수 있다
- [ ] AI 브리핑 문서를 자동 생성하고 편집/내보내기할 수 있다
- [ ] AI 코파일럿이 시나리오 컨텍스트를 이해하고 질문에 답한다
- [ ] 시나리오 검색/필터/비교가 가능하다
- [ ] 외부 서비스 장애 시 자동 재시도 + 복구가 동작한다

## 7. Risks & Mitigations

| 리스크 | 심각도 | 완화 |
|--------|--------|------|
| AI 선택지 생성에 LLM 호출 비용 증가 | High | 시드 옵션 3개로 제한. 캐싱 전략 |
| What-If 분기로 LLM 비용 폭증 | High | 분기당 최대 라운드 제한 (10). 동시 분기 수 제한 (3) |
