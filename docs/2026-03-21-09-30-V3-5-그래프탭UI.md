> 프롬프트: `진행` (prd-next 추천 V3-5 수락)

## 변경 사항

### 신규 파일
- `frontend/src/components/simulation/GraphTab.tsx` — 그래프 탭 메인 컴포넌트. graph_data 1회성 fetch, 엔티티/관계 필터 pill UI, 노드 클릭 → NodeDetailPanel, filteredGraphData 계산.

### 수정 파일
- `frontend/src/types/simulation.ts` — NodeDetail, GraphFilters 인터페이스 추가
- `frontend/src/components/simulation/GraphViewer.tsx` — standalone 모드 (380x320 뷰포트, D3 zoom/pan, r=7 노드, 전체 이름 표시), selectedNodeId (하이라이트 + 관련 엣지 강조 + 비관련 노드 dim), onNodeClick (클릭 핸들러)
- `frontend/src/components/simulation/SimulationPanel.tsx` — "graph" 탭 추가 (Tab 유니온 확장, showGraphTab 조건, GraphTab 렌더)

### 핵심 설계
1. **1회성 fetch**: useLiveSimulation 미수정. GraphTab에서 getLiveGraphData 직접 호출 (마운트 시 1회)
2. **필터 pill UI**: COLOR_MAP 색상 매칭, active=filled / inactive=outlined
3. **하이라이트**: selectedNodeId 변경 시 별도 useEffect로 D3 selection 업데이트 (시뮬레이션 재시작 없음)
4. **하위 호환**: IntermediateResults.tsx 미수정. standalone/selectedNodeId/onNodeClick 모두 optional prop
