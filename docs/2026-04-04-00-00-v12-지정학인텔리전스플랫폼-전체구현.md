## 변경 요약

v12 지정학 인텔리전스 플랫폼의 4개 PRD를 모두 구현. MiroFish 의존성을 완전 제거하고, 독립 Simulation Service + PostgreSQL NOTIFY/LISTEN + SSE 기반 실시간 아키텍처로 전환.

### PRD-0: 인프라 준비 (0fba079, +845줄)
- STIX2 온톨로지 12종 SDO 추가 (행위자 6, 자산 1, 이벤트 3, 지리 2)
- 15종 관계 유형 정의 (edge_types.py)
- 6개 OSINT 소스 매핑 규칙 (mapping_rules.py) — lng/lon 지뢰 반영
- Alembic 002 마이그레이션: ontology_edge_history + simulation_events (UUID PK)
- pg_event_bus.py: emit/listen/catch-up (8KB 오버플로 처리)
- simulation_stream.py: GET /api/scenario/{id}/stream SSE 엔드포인트

### PRD-1: Simulation Service 골격 (36558a6, +626줄)
- simulation-service/ 독립 서비스 생성 (FastAPI + LangGraph)
- SimulationState TypedDict 17필드
- StateGraph 9노드 + 조건부 엣지 (analyze→relations→actors→configure→round→results→intervene→decision→report)
- AsyncPostgresSaver 체크포인터 (interrupt_before=check_intervention)
- SimulationEventEmitter: 6종 이벤트 발행
- SimulationCommandListener: start/stop/decision 명령 수신
- Gateway simulation_v2 라우터: start_v2, decide_v2

### PRD-2: 에이전트 엔진 (4651fe6, +890줄)
- 9개 stub 노드 → 실제 LLM 에이전트 구현으로 교체
- analyze: ShadowBroker OSINT 수집 + LLM 정세 요약
- relations: LLM 엔티티/관계 추출
- actors: 국가별 에이전트 프로필 LLM 생성 (16개국 사전 정의)
- round: asyncio.gather 병렬 에이전트 호출, 25종 행동 유형
- results: DecisionEngine 연동 (엔진 코드 복사, v12 확장)
- intervene: 긴장도 임계값(0.6) 기반 개입 트리거
- report: LLM 인텔리전스 브리핑 생성
- osint_injector: SB /api/live-data/fast+slow 라운드별 주입

### PRD-3: 프론트엔드 통합 + 레거시 정리 (38d3d93, +468/-5093줄)
