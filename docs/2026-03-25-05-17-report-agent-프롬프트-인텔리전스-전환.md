## 변경 요약
1. **도구 설명 상수(TOOL_DESC_*)**
   - `시뮬레이션 그래프` → `지식 그래프`
   - `시뮬레이션 결과` → `시나리오 분석 결과`
   - `여론` 계열 표현 일부를 `정보 동향`으로 교체
   - `TOOL_DESC_INTERVIEW_AGENTS`에서 OASIS/소셜 에이전트 중심 표현을 `시뮬레이션 환경`/`시나리오 행위자` 중심으로 전환

2. **개요 계획 프롬프트(PLAN_*)**
   - `미래 예측 보고서` → `정보 분석 보고서`
   - `시뮬레이션 세계` → `분석 시나리오`
   - `전지적 시점` → `수석 분석관 시점`
   - `에이전트` → `행위자`
   - `미래의 예연` → `시나리오 분석 결과`
   - JSON 출력 구조, 섹션 수 제한(2~5), 템플릿 변수는 유지

3. **섹션 생성 프롬프트(SECTION_SYSTEM_PROMPT_TEMPLATE)**
   - 역할을 `국가 안보 정보 분석관`으로 전환
   - 핵심 이념/규칙 문구를 시나리오 분석 기반 인텔리전스 평가 맥락으로 전환
   - `행위자의 행동과 성명` 인용 요구로 수정
   - 상단에 용어 변환 규칙 추가:
     - CREATE_POST/create_post → 공식 성명 발표
     - QUOTE_POST/quote_post → 타국 성명에 대한 공식 반응
     - REPOST/repost → 동맹국 입장 지지/전파
     - LIKE_POST/like_post → 암묵적 동의 신호
     - FOLLOW/follow → 외교적 연계 강화
     - DO_NOTHING/do_nothing → 전략적 관망
     - 금지어 목록 명시
   - 기존 형식 규정(제목 금지, **굵게** 사용), 도구 호출 규약(`<tool_call>`), Final Answer 규칙 유지
   - 예시 문구에서 소셜 미디어 표현 제거 및 정보/안보 분석 맥락으로 교체

4. **SECTION_USER_PROMPT_TEMPLATE / REACT_* / CHAT_SYSTEM_PROMPT_TEMPLATE**
   - `시뮬레이션 데이터` → `분석 데이터`로 치환
   - 채팅 역할 `시뮬레이션 예측 도우미` → `정보 분석 도우미`
   - 구조/포맷/변수는 유지
