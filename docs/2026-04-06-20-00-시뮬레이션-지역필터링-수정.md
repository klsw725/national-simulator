# 시뮬레이션 OSINT 지역 필터링 버그 수정

**날짜**: 2026-04-06
**프롬프트**: "난 호르무즈 해협 관련해서 조사를 시켰는데 왜 내용은 한중일 해역 얘기가 나오냐?" → "수정해줘"

## 문제

호르무즈 해협(bbox: [54, 24, 58, 28])을 선택해 시뮬레이션을 실행하면, 시드 생성 단계에서는 정상적으로 해당 지역 OSINT만 수집하지만, 이후 시뮬레이션 서비스의 상황 분석(analyze) 및 매 라운드(round) 노드에서 ShadowBroker API를 **bbox 없이** 호출하여 전 세계 OSINT를 수신했다. 동아시아 해역 데이터가 압도적으로 많아 LLM이 한중일 관련 내용을 생성하는 현상.

## 근본 원인

`simulation-service/app/services/osint_injector.py`의 `fetch_latest_osint()` 함수가 `region_bbox` 파라미터를 선언만 하고 실제 API 호출에 전혀 사용하지 않았음. 또한 `SimulationState`에 `region_bbox` 필드가 없어 그래프 노드가 지역 정보를 참조할 수 없었고, 백엔드의 NOTIFY payload에도 `region_bbox`가 포함되지 않았음.

## 변경 파일

| 파일 | 변경 내용 |
|------|-----------|
| `simulation-service/app/graph/state.py` | `SimulationState`에 `region_bbox: list[float]` 필드 추가 |
| `simulation-service/app/services/osint_injector.py` | `fetch_latest_osint()`에서 `region_bbox`를 ShadowBroker API의 s/w/n/e 쿼리 파라미터로 변환하여 전달 |
| `simulation-service/app/graph/nodes/analyze.py` | `fetch_latest_osint()` 호출 시 `state["region_bbox"]` ���달 |
| `simulation-service/app/graph/nodes/round.py` | `fetch_latest_osint()` 호출 시 `state["region_bbox"]` 전달 |
| `simulation-service/app/services/command_listener.py` | `initial_state`에 `region_bbox` 필드 추가 (command에서 읽어 주입) |
| `backend/app/routers/simulation_v2.py` | legacy/v2 모두 DB에서 `region_bbox` 조회 후 NOTIFY payload에 포함 |
| `backend/app/routers/wargame_v2.py` | retry 경로에서도 DB에서 `region_bbox` 조회 후 NOTIFY payload에 포함 |

## 데이터 흐름 (수정 후)

```
사용자: "호르무즈 해협" (bbox: [54, 24, 58, 28])
  ↓
시나리오 생성 → DB에 region_bbox 저장
  ↓
시뮬레이션 시작 (simulate / start_v2 / retry)
  → DB에서 region_bbox 조회 → NOTIFY payload에 포함
  ↓
simulation-service (command_listener)
  → initial_state에 region_bbox 주입
  ↓
analyze_situation_node / run_round_node
  → fetch_latest_osint(region_bbox=state["region_bbox"])
  → ShadowBroker API에 ?s=24&w=54&n=28&e=58 쿼리 전달
  → 호르무즈 해협 OSINT만 수신
```
