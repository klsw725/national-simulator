# V3-4 DuckDuckGo 웹 검색 통합 (M1-M2)

> 날짜: 2026-03-21
> 프롬프트: `진행` (prd-next 추천 V3-4 M1-M2 수락)

## 변경 사항

### 신규 파일
- `backend/app/services/web_search.py` — WebSearchService 클래스. `search_news(keywords)` (DDGS 뉴스 검색, 인메모리 캐시 1h TTL, 시드당 최대 3회 검색), `format_for_seed(results)` (마크다운 포맷, 최대 8개 기사, 중복 제거), `extract_keywords(question, region_name, actors)` (시나리오 정보에서 검색 키워드 자동 추출).

### 수정 파일
- `backend/pyproject.toml` — `duckduckgo-search>=7.0.0` 의존성 추가 (설치: 8.1.1)
- `backend/app/models/scenario.py` — `SimulationParams`에 `web_search_enabled: bool = False` 필드 추가
- `backend/app/services/seed_generator.py` — `generate()`에 `web_search_enabled` 파라미터 추가. 활성화 시 WebSearchService로 뉴스 검색 → SEED_GENERATION_PROMPT에 "최근 뉴스" 섹션 주입. 메타데이터에 `web_search_count` 추가.
- `backend/app/routers/simulation.py` — `generate_seed`에서 시나리오의 `simulation_params.web_search_enabled`를 조회하여 SeedGenerator에 전달
- `frontend/src/types/simulation.ts` — `SimulationParams`에 `web_search_enabled: boolean` 추가. `ScenarioFormData.simulation_params`에도 추가.
- `frontend/src/components/simulation/ScenarioForm.tsx` — 고급 설정에 "웹 검색 보강" 토글 추가

### 설계 결정
1. **동기 호출**: `ddgs.news()`는 동기 API. SeedGenerator의 async generate() 내에서 호출 (I/O 블로킹이지만 검색 3회 이내로 영향 미미).
2. **Graceful fallback**: 웹 검색 실패 시 경고 로그만 남기고 기존 시드 생성 계속 진행.
3. **M3-M4는 W4**: OASIS 에이전트 도구 주입은 MiroFish simulation_runner 수정 필요. 별도 일정.
