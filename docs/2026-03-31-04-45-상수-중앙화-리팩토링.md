### Step 1: Find hardcoded values
Search for these patterns in `/home/swlee/osint-simulator/backend/app/`:
1. **Timeout values**: numbers like `30`, `60`, `120`, `180`, `300` used as timeouts in seconds
2. **Polling intervals**: sleep/interval durations
3. **Retry counts**: max retries, max attempts
4. **Default limits**: default page sizes, max results
5. **Status strings**: repeated status literals like "completed", "failed", "starting" etc.

Focus on `backend/app/services/` and `backend/app/clients/` — these have the most scattered constants.

### Step 2: Group by domain
Create constants files:

**`/home/swlee/osint-simulator/backend/app/constants.py`** — Centralized project-wide constants:

```

### Step 3: Replace hardcoded values
For each constant found, replace the magic number/string with the named constant from the module.

3. Do NOT extract values inside test files or external/
4. Keep the constant names descriptive and grouped by domain
5. If a value is already defined in `config.py`/`settings`, do NOT duplicate it
