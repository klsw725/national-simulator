## 변경 요약

### M1: 코파일럿 API + 컨텍스트 빌더
- `backend/app/services/copilot_context.py` 신규: CopilotContextBuilder
  - 시나리오 메타데이터 + 시드 요약 (2000자) + 결과 통계 (행위자 TOP 10) + 보고서 요약 (1500자) + 지정학 이벤트 수를 LLM 컨텍스트 문자열로 구성
- `backend/app/services/copilot.py` 신규: CopilotService
  - LLM tool-use 루프 (최대 5 라운드)
  - 대화 이력 관리 (conversation_id 기반)
  - 시스템 프롬프트에 시나리오 컨텍스트 주입
  - 제안 질문 자동 생성 (사용된 도구 기반)
- `backend/app/routers/copilot.py` 신규: POST /api/copilot/chat
- `backend/app/main.py` 수정: copilot 라우터 등록

### M2+M3: 코파일럿 도구
- `backend/app/services/copilot_tools.py` 신규: 7개 도구 + OpenAI tools 스키마
  - `search_observations`: 소스 유형별 관측 데이터 검색
  - `count_entities`: 소스 유형별 엔티티 집계
  - `analyze_simulation_actions`: 행위자/유형/라운드별 액션 통계
  - `get_geopolitics_summary`: 유형/행위자/라운드별 지정학 이벤트 분포
  - `compare_scenarios`: ScenarioComparator 재사용으로 2개 시나리오 비교
  - `suggest_whatif`: 가설 기반 What-If 파라미터 제안
  - `generate_summary`: 핵심 발견 데이터 추출 (행위자, 액션, 보고서 발췌)

### M4: 프론트엔드 채팅 UI
- `frontend/src/components/simulation/CopilotPanel.tsx` 신규: 채팅 인터페이스
  - 메시지 입력 (Enter 전송) + 응답 표시 (pre-wrap)
  - 도구 사용 배지 (🔧 tool_name, 보라색)
  - 제안 버튼 (→ 다음 질문, 마지막 응답에만)
  - 초기 제안 3개 (요약, 공격적 행위자, 지정학 분석)
  - 스크롤 자동 이동 + 로딩 표시
- `frontend/src/lib/gatewayApi.ts` 수정: copilotChat 함수 추가
- `frontend/src/components/simulation/SimulationPanel.tsx` 수정: "코파일럿" 탭 추가 (시나리오 선택 시 표시)
