## 변경 요약

### 1) `backend/app/services/causal_extractor.py` 신규 추가
- AsyncOpenAI 기반 인과 엣지 추출 서비스 추가
- LLM 호출 패턴을 기존 `copilot.py`와 동일하게 적용
  - `model=settings.llm_model_name`
  - `temperature=0.1`
  - `max_tokens=2048`
  - `extra_body={"chat_template_kwargs": {"enable_thinking": False}}`
- JSON 파싱 폴백 구현
  - 전체 문자열 `json.loads()` 시도
  - ```json ... ``` 블록 추출 시도
  - `[` ~ `]` 구간 추출 시도
- 응답을 `CausalEdge`로 변환 (`provenance="llm_extracted"`)
- `validate_with_data` 구현
  - `pgmpy.estimators.CITests.chi_square` 사용
  - 데이터 30행 이상일 때만 검증
  - 독립 기각 실패 시 confidence 약화 및 provenance 태깅
  - 컬럼 미존재/검증 불가 엣지는 `unverified` 태깅 후 유지
- `extract_and_validate` 통합 메서드 추가

### 2) `backend/app/services/causal_narrator.py` 신규 추가
- DAG 경로 기반 인과 내러티브 생성 서비스 추가
- 타겟 변수의 조상 경로를 최대 5개까지 수집 후 경로별 기여도 매핑
- LLM 내러티브 생성 호출 추가 (`enable_thinking=False` 포함)
- `enrich_briefing` 구현
  - 귀속값 없으면 원문 반환
  - 내러티브 생성 후 `## 부록` 앞에 `## 인과 분석` 섹션 삽입
  - 부록이 없으면 문서 끝에 추가

### 3) `backend/app/causal/models.py` 확장
- 아래 요청/응답 모델 추가 (기존 모델 유지)
  - `CausalExtractRequest`
  - `CausalExtractResult`
  - `CausalNarrateRequest`
  - `CausalNarrateResult`

### 4) `backend/app/routers/causal.py` 확장
- `/api/causal/extract` POST 추가
  - `scenario_id`가 있으면 `build_dataframe()` 시도
  - `extract_and_validate()` 호출
  - `CausalExtractResult` 반환
- `/api/causal/models/{model_id}/paths` GET 추가
  - DB `dag_json` 조회, 없으면 도메인 DAG 폴백
  - target까지 경로 추출(max_paths)
  - fitted 모델이면 `_reasoner.attribute()`로 attributions 반환
- `/api/causal/narrate` POST 추가
  - model_id로 DAG 로드 (없으면 도메인 DAG)
  - `CausalNarrator.generate_narrative()` 호출
  - `CausalNarrateResult` 반환

### 5) `backend/app/services/briefing_generator.py` 확장
- `generate()`에서 `is_sparse` 분기 직전 로직 추가
  - 도메인 DAG의 `propagates_to` 엣지 기반 인과 참고 섹션 생성
  - 생성된 섹션을 `extra_sections` 앞에 prepend

### 6) `external/mirofish-backend/app/services/ontology_generator.py` 확장
- `ONTOLOGY_SYSTEM_PROMPT`의 edge_types 안내 뒤에 인과 엣지 타입 요구사항 추가
  - `CAUSES`, `ENABLES`, `PREVENTS` 필수 포함 지시
  - 도메인 특화 관계와 함께 포함하도록 명시
