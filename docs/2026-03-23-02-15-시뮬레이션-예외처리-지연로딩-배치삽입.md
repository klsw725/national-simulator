**Part A: Fix 3 silent fallback responses (simulation.py)**

Read backend/app/routers/simulation.py. Find these 3 patterns where `except Exception` returns a fallback dict instead of an error response:

Pattern 1 — Around the `get_live_actions` equivalent endpoint (search for `"actions": [], "count": 0` being returned in an except block). Change it to re-raise or return HTTP 502.

Pattern 2 — Around the `get_live_graph_data` equivalent (search for returning empty `{}` in an except block). Change to HTTP 502.

Pattern 3 — Around the `get_live_stats` equivalent (search for `"status": "unknown"` in an except block). Change to HTTP 502.

For EACH, change from:
```python
except Exception:
    return {"fallback": "value"}
```
To:
```python
except Exception as e:
    logger.exception("Description of what failed")
    raise HTTPException(status_code=502, detail="Upstream service error")
```

**Part B: Lazy-load panels (page.tsx)**

Read frontend/src/app/page.tsx. Change the imports for SimulationPanel and OSINTPanel from eager to dynamic:

Current:
```typescript
import SimulationPanel from "@/components/simulation/SimulationPanel";
```
```typescript
import OSINTPanel from "@/components/osint/OSINTPanel";
```

Change to:
```typescript
const SimulationPanel = dynamic(
  () => import("@/components/simulation/SimulationPanel"),
  { ssr: false }
);
const OSINTPanel = dynamic(
  () => import("@/components/osint/OSINTPanel"),
  { ssr: false }
);
```

Make sure `dynamic` is already imported from "next/dynamic" (it should be — MaplibreViewer already uses it).

**Part C: Batch INSERT for scenario_observations (simulation.py)**

Find the loop INSERT pattern in simulation.py around line 108 (search for `INSERT INTO scenario_observations` inside a `for obs_id in used_obs_ids` loop).

Change from:
```python
for obs_id in used_obs_ids:
    so_id = f"so_{uuid.uuid4().hex[:12]}"
    await conn.execute(
        "INSERT INTO scenario_observations ...",
        so_id, scenario_id, obs_id, now,
    )
```

To:
```python
if used_obs_ids:
    values = [(f"so_{uuid.uuid4().hex[:12]}", scenario_id, obs_id, False, now) for obs_id in used_obs_ids]
    await conn.executemany(
        "INSERT INTO scenario_observations (id, scenario_id, observation_id, used_in_seed, created_at) VALUES ($1, $2, $3, $4, $5)",
        values,
    )
```
